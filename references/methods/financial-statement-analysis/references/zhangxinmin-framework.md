# 张新民财务分析框架（实操版）

来源：《火眼金睛读财报》。本文件只保留**可直接执行的判定口径与公式**，含实践中校准过的阈值。

---

## 0. 总纲：三张表是一张表

| 报表 | 张新民定位 | 回答的问题 | 性质 |
|---|---|---|---|
| 资产负债表 | **底子** | 家底厚不厚、资源怎么摆、钱从哪来 | 时点数 |
| 利润表 | **面子** | 能力强不强、利润怎么来的 | 时期数 |
| 现金流量表 | **日子** | 手里有没有钱过日子 | 时期数 |

核心关系：现金流量表 = 资产负债表「货币资金」一行的变动说明；利润表的净利润 = 资产负债表「股东权益」增量的展开说明。

**分析顺序建议**：利润表（真伪）→ 资产负债表（家底与战略）→ 现金流量表（造血）→ 三表勾稽（验真）→ 好企业定性。

## 1. 利润表四步法（企业竞争力）

### 第一步：营收成长性
- 口径：年度营业收入同比增速，至少看 5—10 年，CAGR 与单年增速并列。
- 判定：
  - 持续正增长 → 市场扩张中
  - 持平 / 萎缩 → **不必然等于未来不行**，需结合行业 beta 与宏观环境判断（张新民明确提示）
- 关键动作：**必须做同业对照**。跌幅显著大于同业 ⇒ 市场份额在流失，不能全归因于行业。
- 补充：拆分单季增速，识别下滑是否加速（如 Q1 尚正、Q2 转负）。

### 第二步：净利润增长性
- 理想态：净利润增速 **>** 营业收入增速（盈利效率提升）。
- 净利增速 < 营收增速 ⇒ 成本控制或经营效率有问题。
- 长周期看 CAGR 对比（净利 CAGR vs 营收 CAGR）；当期看「超额增速 = 净利增速 − 营收增速」。
- **超额增速归零是重要信号**：若前几年靠压费用取得超额，一旦归零说明降本红利吃完。

### 第三步：营业利润稳定性
- 指标：**营业利润 ÷ 利润总额**（十年均值与当期值）。
- 优秀线：≈100%，营业外收支净额绝对值极小。
- 辅助：扣非净利润 ÷ 归母净利润（≥90% 为佳）。
- 依赖营业外收入、补贴、资产处置的利润结构不可持续。

### 第四步：盈利结构质量 —— 三支柱、两搅局

```
营业利润
├─ 三支柱
│   ├─ 核心利润（主营根基）
│   ├─ 其他收益（政府补贴等）
│   └─ 杂项收益（投资收益、利息收入、公允价值变动、资产处置）
└─ 两搅局（减项）
    ├─ 信用减值损失
    └─ 资产减值损失
```

**核心利润 = 营业收入 − 营业成本 − 税金及附加 − 销售费用 − 管理费用 − 研发费用 − 利息费用**

判定：
- 核心利润 / 营业利润 ≥ 90% → 优秀；70—90% → 良好；<70% → 需警惕"在玩不在干"
- 其他收益占比上升 → 补贴依赖度上升（注意区分"补贴金额下降但占比上升"）
- 两搅局持续扩大 → 资产质量恶化信号

**口径提示（必做双口径）**：数据源通常无「利息费用」细项。若企业财务费用为负（净利息收入），用财务费用净额会使核心利润偏高。严格口径 = 剔除全部财务费用影响后重算，两个口径都要报。

## 2. 资产负债表三步法（偿债能力与发展态势）

### 第一步：资产规模变化
- 期末 vs 期初总资产变动率。
  - 基本持平 → 原有规模运营，成长性不突出
  - 期末显著大于期初（如 +20% 以上）→ 快速发展
  - 期末显著小于期初 → 经营能力或对外扩张能力下降
- 必须看**时间序列**（5—10 年 CAGR + 逐年增速），识别"何时停的"。

### 第二步：资产结构变化
两个维度：
1. **流动 / 非流动资产结构**：流动资产比重上升通常意味流动性增强（但需看内部构成是否只是现金堆积）。
2. **经营资产 / 投资资产结构**：
   - 经营资产 = 固定资产 + 在建工程 + 无形资产 + 存货 + 应收票据及应收账款（+ 应收款项融资）
   - 投资资产 = 长期股权投资 + 交易性金融资产（+ 其他权益工具投资等）
   - 货币资金不计入任何一侧（既支持经营也支持投资）
3. 关键衍生指标：**投资资产 / 经营资产** 比值的多年走势。持续上升 + 经营资产绝对额下降 = 战略从"做实业"转向"管钱"。

### 第三步：资产与负债的三个关系
1. **流动比率** = 流动资产 / 流动负债。传统 2:1 安全，但**必须结合流动资产结构**：若流动资产主要是现金与理财，1.0 出头亦可能极安全；若主要是存货与应收，2.0 亦可能紧张。
2. **资产负债率** = 总负债 / 总资产。需结合**债务结构**（有息 vs 无息）判断，不可孤立看高低。
   - 核心洞察：制造业龙头的负债常以应付账款、销售返利计提、合同负债等**经营性负债**为主，是对上下游的占款能力，**不是风险**。
3. **资产有息负债率** = 有息负债（短期借款 + 一年内到期非流动负债 + 长期借款 + 应付债券 + 租赁负债）/ 总资产。
   - ≥50% 需重点关注；<25% 基本不依赖债务融资。
   - 附加：**经营性负债占比** = 1 − 有息负债 / 总负债。

**必查结构隐患**：有息负债的期限结构。长期借款骤降、短期借款占比飙升 = 用短债置换长债压利息成本，现金充裕时无害，但提高对再融资环境的依赖。

## 3. 现金流量表四步法（运作脉搏）

### 第一步：经营活动现金流的充分性
**核心利润获现率 = 经营活动现金流量净额 ÷ (核心利润 + 其他收益)**
- 理想区间 **1.2 — 1.5**（张新民口径；重资产企业应更高）
- 双口径并列：分母也可用纯核心利润，差异即其他收益的影响
- 辅助指标：
  - 净利润现金含量 = 经营现金流净额 / 净利润
  - 销售收现比 = 销售商品提供劳务收到的现金 / 营业收入
    - 长期 <1 且应收票据庞大 = 票据结算的商业模式特征，非异常
    - 收现比抬升需甄别：是回款变好，还是经销商不再用票据打款 / 不再提前囤货（配合应收票据、合同负债同步看）
- 十年均值 <1 且个别年份接近 0 → 获现质量历史波动大

### 第二步：投资活动现金流出的扩张含义
- **购建固定资产、无形资产和其他长期资产支付的现金**（资本支出）
  - 规模大 → 强化生产经营能力，为未来扩张
  - 规模小 → 渐进式建设，或**已停止扩产**
  - **黄金指标：资本支出 / 折旧摊销**
    - ≥1.0：产能至少维持
    - <1.0：当期投入少于当期消耗，**固定资产被净消耗**
    - 需给出绝对缺口（折旧 − 资本支出）与固定资产净值可支撑年限
- **投资支付的现金** 占比高 → 对外投资扩张或频繁短期理财交易
  - 结合商誉判断：商誉极低 ⇒ 连产业并购都没做，只是买理财
- 产能投资占投资流出比 = 资本支出 / 投资活动现金流出合计

### 第三步：筹资活动的规模、结构与支持方向
- 资金来源：股权融资（吸收投资收到的现金）vs 债务融资（取得借款收到的现金）
- 资金用途：支持投资 / 支持经营 / 还款付息分红 / 暂存
- **过度筹资判定**：经营现金流已能覆盖「资本支出 + 分红」，却仍大量净融入资金 → 张新民定义的过度筹资。风险通常不大，但资金运用效率偏低。
- 存贷双高识别：现金类资产与有息负债同时巨额，且借款/偿还金额远超资本支出数十倍 → 票据与理财的滚动腾挪，不是扩产融资。

### 第四步：什么样的现金流结构能持续发展
教科书组合：**经营活动现金流为正、投资活动为负、筹资活动为负**（经营养投资、投资完剩余还债分红）。
- 统计十年中该组合出现的年份数（**必须逐年核对，不可凭印象计数**）
- 筹资为正的年份需单独解释原因（是否回购、是否周转性举债）

## 4. 三表勾稽与异常信号

### 4.1 利润表 → 资产负债表（未分配利润）
期末未分配利润 = 期初未分配利润 + 本期净利润 − 提取盈余公积 − 分配股利
- 误差 <0.5% 视为勾稽成立
- **常见"合理的对不上"**：
  1. **股份回购并注销**：按面值冲减股本，差额依次冲减资本公积 → 盈余公积 → 未分配利润。若企业资本公积与盈余公积规模小，大额回购几乎全落在未分配利润上，导致勾稽出现数十亿至数百亿缺口。**用当年回购金额去填缺口，残差 <1 亿即可确认成因。**
  2. **收购少数股权**：溢价冲减资本公积/留存收益
  3. 库存股转回、其他综合收益结转
- 排查动作：追到年报《所有者权益变动表》逐项核对。

### 4.2 现金流量表 → 资产负债表（货币资金）
现金及现金等价物净增加额 = 货币资金期末 − 货币资金期初（理论）
- 实务中**普遍对不上**，因：
  - 现金流量表的「现金」= 现金及现金等价物（排除定期存款、受限资金、票据保证金、存放央行款项）
  - 资产负债表的「货币资金」包含上述全部
- **处理办法（必做）**：构造 **楔子 = 货币资金 − 现金及现金等价物余额**，逐年验证楔子变动能填满差额。
- 楔子巨大时的估值影响：账上货币资金中只有一小部分可自由动用，**净现金必须按可动用口径重算**（实践中曾出现 +788.5 亿 → −218.3 亿的反转）。

### 4.3 综合勾稽（间接法）
经营活动现金净流量 = 净利润 + 非付现费用（折旧摊销、减值）+ 财务费用调整 + 营运资本变动 + 其他调整
- 逐项加总与披露值比对（允许四舍五入误差 <0.1 亿）
- **营运资本三项用资产负债表独立验证**：
  - 存货增加 → 现金流减少
  - 应收（票据+账款+应收款项融资）增加 → 现金流减少
  - 应付（票据+账款）增加 → 现金流增加
- **"其他"调整项占比异常大（如 >30%）需标记**：透明度最低，最可能对应销售返利计提兑付、票据保证金存取，需查年报附注。

### 4.4 平衡验证
资产 = 负债 + 所有者权益，期末与最新一期各验一次。

### 4.5 三条异常信号扫描

| 信号 | 判定方法 |
|---|---|
| 有利润无现金 | 连续盈利但经营现金流为负，且应收或存货急剧增加 |
| 货币资金对不上 | 做楔子分析；楔子能解释则非异常，是口径差异 |
| 未分配利润对不上 | 用回购/少数股权收购解释；无法解释的残差才追查 |

### 4.6 业务模式与现金流特征
- 预收款模式：先收钱后发货 → 有钱没利润 → 有利润没钱
- 钱货两清：收入、利润、现金同步
- 赊销模式：先发货后收款 → 有利润没现金

## 5. 识别好企业（第 18—19 节）

### 5.1 利润表视角
- 三支柱两搅局结构（同 1.4）
- **在"干"还是在"玩"**：核心利润为主 = 在干；投资收益/资产处置为主 = 在玩
- 四步法综合（同第 1 节）

### 5.2 现金流量表视角
- 核心利润获现率（同 3.1），轻资产 1.2—1.5，重资产需更高
- 经营现金流必须持续大幅 > 0（净额为 0 仅能维持周转）
- 投资扩张恰当高效、筹资不盲目

### 5.3 资产负债表视角
1. **资产结构合理，聚焦主营**：经营资产占比高、投资资产适度、减值风险低
2. **负债结构健康**：经营性负债为主、有息负债适度、资产负债率适中
3. **权益结构稳健**：
   - **利润积累占比 = (盈余公积 + 未分配利润) / 归母所有者权益**（越高越强，>90% 极优）
   - **股东入资占比 = (股本 + 资本公积) / 归母所有者权益**
   - **自我造血倍数 = 利润积累 / 股东入资**（>10 倍说明几乎不依赖外部输血）
   - 十年累计股权融资金额（优秀企业接近 0）

### 5.4 资产轻重与经营模式（第 16 节）
- 重资产：固定资产 + 在建工程占比高，折旧摊销负担重
- 轻资产：固定资产占比低，靠品牌/技术/渠道
- **双口径必算**：
  - 全口径 = (固定资产 + 在建工程) / 总资产
  - 经营口径 = (固定资产 + 在建工程) / 经营资产
  - 两者差异全部来自现金类资产稀释分母 → 出现"表轻里重"时两个口径都要报

### 5.5 综合定性（本框架最重要的输出）
把指标分成两类后判断：
- **质量项**：盈利真不真、现金收不收得回、家底实不实、欠不欠钱
- **方向项**：还在不在长、还投不投未来

**核心结论句式**：「X 是一家财务上高度健康、战略上已停止扩张的高质量现金牛企业」——即**"已经长成的好企业"，不是"正在长的好企业"**。

## 6. 关键指标公式速查

| 指标 | 公式 | 参考阈值 |
|---|---|---|
| 核心利润 | 营收 − 营业成本 − 税金及附加 − 销售/管理/研发费用 − 利息费用 | — |
| 核心利润占比 | 核心利润 / 营业利润 | ≥90% 优秀 |
| 核心利润率 | 核心利润 / 营业收入 | 越高越好，看十年趋势 |
| 营业利润稳定性 | 营业利润 / 利润总额 | ≈100% 优秀 |
| 核心利润获现率 | 经营现金流净额 / (核心利润 + 其他收益) | 1.2—1.5 |
| 净利润现金含量 | 经营现金流净额 / 净利润 | >1.2 良好 |
| 销售收现比 | 销售商品收到现金 / 营业收入 | 结合模式看趋势 |
| 资本支出/折旧摊销 | 购建固定资产等支付现金 / (折旧 + 摊销) | ≥1.0 维持产能 |
| 自由现金流 | 经营现金流净额 − 资本支出 | >0 且稳定 |
| 现金周期 | 存货周转天数 + 应收周转天数 − 应付周转天数 | 负值 = 占用上下游资金 |
| 资产有息负债率 | 有息负债 / 总资产 | <50%（<25% 优） |
| 经营性负债占比 | 1 − 有息负债 / 总负债 | 越高议价力越强 |
| 利润积累占比 | (盈余公积 + 未分配利润) / 归母权益 | >90% 极优 |
| 自我造血倍数 | 利润积累 / 股东入资 | >10 倍 |
| 投资资产/经营资产 | (长投 + 交易性金融资产) / 经营资产 | 看趋势 |
| 楔子 | 货币资金 − 现金及现金等价物余额 | 用于勾稽 |
| 净现金（可动用口径） | 现金及现金等价物 − 有息负债 | 优于货币资金口径 |

## 7. 交付前自检清单

- [ ] 所有增速、比率均给出**多年序列**，不只用单期数据
- [ ] 核心利润、净现金、获现率均做了**双口径**并列
- [ ] 同业对照至少 2 家（同行龙头）
- [ ] 三表勾稽五项全部跑过，缺口给出成因或标注"需追年报"
- [ ] 结论区分「质量项」与「方向项」，不做笼统好坏判断
- [ ] 明确写出"转折的关键变量是什么"（通常落在营收拐点）
- [ ] 附免责声明
