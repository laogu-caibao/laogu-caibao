# 管理决策框架：把财务结论变成可执行的汇报

当分析结论需要面向管理层 / 投资委员会时，用四个框架重新组织。**分析结论不变，只是换表达结构。**

---

## 1. 金字塔原理（用于报告主结论层）

### 1.1 SCQA 序言（开篇 100—200 字）

| 要素 | 内容 | 财务分析中的写法 |
|---|---|---|
| **S** 情境 | 共识背景 | 公司行业地位、市值、当前估值 |
| **C** 冲突 | 打破共识的事实 | 营收 X 年连降 / 利润创新高但不扩产 |
| **Q** 疑问 | 由此产生的问题 | 这是财务问题还是经营问题？还值不值得持有？ |
| **A** 答案 | 中心论点（塔尖） | 一句话定性 + 唯一关键变量 |

### 1.2 塔尖中心论点的标准句式

> 「XX 是一家**财务上高度健康、战略上停止扩张**的高质量现金牛企业。它的问题不在财务真伪，而在成长方向；**决策的关键变量只有一个——营业收入能否出现拐点。**」

要求：一句话内同时给出**定性**与**唯一关键变量**。不给关键变量的结论等于没结论。

### 1.3 纵向结构：三条一级论据 + 九项支撑数据

按 MECE 分组，典型三段：

| 论据 | 分组逻辑 | 财务映射 |
|---|---|---|
| 【真】质量 | 利润真不真、现金收不收得回、家底实不实 | 核心利润占比、三表勾稽、利润积累占比、获现率 |
| 【停】方向 | 还在不在长、还投不投未来 | 资本支出/折旧、在建工程、经营资产变动、投资/经营比 |
| 【变】传导 | 风险是否已开始兑现 | 经营现金流降幅 vs 营收降幅、合同负债、票据体系 |

每条论据配 3 项支撑数据（共 9 项），**每项都是一个具体数字 + 判定**。

### 1.4 横向排序
- 按「真伪 → 方向 → 传导」的时间/逻辑顺序，不按报表顺序
- 每组内部按重要性递减

## 2. 5W2H（用于把单一病灶拆透）

对**一个核心判断**（如"公司停止扩张"）逐问作答，每问用财报数据回答：

| 问 | 要回答的内容 | 典型数据源 |
|---|---|---|
| **WHAT** 是什么 | 现象的可量化定义 | 资本支出/折旧 = 0.34 |
| **WHY** 为什么 | 根因，往往不是"没钱"而是"没找到更优用途" | 回购金额、ROE、项目回报率 |
| **WHERE** 在哪发生 | 哪些科目、哪些业务、哪些区域 | 在建工程、经营资产结构、分部数据 |
| **WHEN** 何时开始 | 拐点年份，之后是否持续 | 逐年序列（2023 见顶→连续回落） |
| **WHO** 涉及谁 | 对谁有影响（股东、渠道、员工） | 合同负债、经销商打款、分红 |
| **HOW** 怎么发生 | 传导机制 | 不扩产 → 产能净消耗 → 收入下滑 → 现金流下滑 |
| **HOW MUCH** 多严重 | 量化损失与剩余年限 | 年产能净消耗 33.4 亿、固定资产 10 年归零、超额增速归零 |

**最有价值的两问通常是 WHY 与 HOW MUCH**：
- WHY 要挖到"管理层认为找不到回报率高于回购自身的投资项目"这类决策层原因，而不是停在"行业不好"
- HOW MUCH 必须给出**绝对量与剩余年限**，让人能感知量级

## 3. 现象 - 原因 - 方案（用于风险汇报）

### 3.1 三段式模板

```
【现象】<可量化数据 + 与标准的偏离>
【原因】<根因链条，用 → 连接，至少 3 层>
【方案】<对应行动编号，如 A6 / R2>
```

### 3.2 根因链条示例

> **现象**：2026H1 经营现金流 188.1 亿，同比 −33.6%，降幅是营收降幅（−8.15%）的 4.1 倍。
> **原因**：营收下滑 → 经销商打款意愿下降（合同负债 −44.3%）→ 票据结算体系收缩（应收票据+应收款项融资四年 −77.1%）→ 渠道蓄水池功能减弱，营收波动被放大传导至现金流。
> **方案**：A1（营收拐点监测）+ A2（合同负债 ≥120 亿）。

### 3.3 风险分级

| 级别 | 定义 | 呈现 |
|---|---|---|
| 高 | 已在发生且不可逆或加速 | 红色标签 |
| 中 | 已发生但可逆 | 橙色标签 |
| 低 | 潜在风险，需监测 | 黄色标签 |

**重要技巧**：识别"多个风险同源"。若 4—5 项预警指向同一事实（如"不再扩张"），必须在汇报中明确指出——**不是五个分散的毛病，是同一个事实在五个维度上的投影**。这是提升汇报价值的关键动作。

## 4. SMART（用于把结论变成可考核目标）

### 4.1 目标表结构（五列齐全）

| 编号 | S 目标（具体） | M 衡量（量化指标） | A 可达（依据） | R 相关（关联的风险/论据） | T 时限 |

### 4.2 分组方式

- **核心组（决定方向）**：营收增速转正、合同负债回升、市场份额监测
- **质量组（决定真假）**：核心利润率下限、费用拐点、资本支出/折旧 ≥1.0、获现率 ≥1.2
- **结构组（决定安全边际）**：债务期限结构、分红可持续性、信息透明度

### 4.3 目标条目示例

| 编号 | S | M | A | R | T |
|---|---|---|---|---|---|
| A1 | 单季营收增速转正 | 季度营收同比 ≥0%，连续两季 | 2026Q1 曾 +3.52%，证明可达 | 对应【停】方向风险 | 2027Q2 前 |
| A6 | 恢复产能再投入 | 资本支出/折旧摊销 ≥1.0 | 历史峰值 2.5，资金充足 | 产能净消耗 33.4 亿/年 | 2027 年报 |

### 4.4 决策规则（让结论可回溯）

把"见仁见智"变成**可回溯的触发规则**：

| 投资者类型 | 触发条件 | 观察指标 |
|---|---|---|
| 收息型 | 达标 | 获现率 ≥1.2、分红覆盖倍数 ≥2 |
| 价值型 | 需 A1 + A2 同时达标，且质量组未触发 | 营收拐点 + 合同负债 |
| 成长型 | 只认 A6 | 资本支出/折旧 |

### 4.5 红黄绿监测看板

每项跟踪指标给出：**当前值 / 阈值 / 状态（红黄绿）/ 下一检验时点**。

---

## 5. 四框架的组装顺序（推荐章节结构）

```
第 0 章  SCQA 序言 + 塔尖中心论点                    ← 金字塔
第 1 章  三条一级论据 + 九项支撑数据                  ← 金字塔（纵向+横向）
第 2 章  核心病灶的 5W2H 拆解                        ← 5W2H
第 3 章  风险清单：现象-原因-方案                     ← 现象原因方案
第 4 章  SMART 目标表                                ← SMART
第 5 章  决策规则与红黄绿看板                         ← SMART
附录 A   企业体检表（全部指标逐项判定）
附录 B   三表深度分析（利润表/资产负债表/现金流量表）
附录 C   三表勾稽验证
附录 D   同业对照
附录 E   数据来源与口径说明
```

**原则**：管理层只看第 0—2 章就能做决策；第 3—5 章给执行层；附录给需要验证细节的人。
