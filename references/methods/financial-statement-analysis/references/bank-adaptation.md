# 商业银行财报分析适配指南

> 触发条件：分析对象为银行（申万行业"银行"）、保险、券商、信托等金融机构时**必读**。
> 首次实战：兴业银行 601166（2026-09）。

## 一、为什么必须适配

张新民《火眼金睛读财报》的框架以**制造业与一般工商企业**为样板。商业银行的报表结构与之存在根本差异，直接套用会产生方向性误判——最典型的一例是"核心利润获现率"：银行十年经营现金流可以为负（贷款投放是经营现金流出），若据此判定"有利润无现金、疑似虚构收入"，结论完全相反。

**处理原则**：保留张新民框架的**逻辑内核**（利润是"干"出来的还是"玩"出来的、三表是否自洽、利润积累是否内生），**替换**不适用的具体指标，并在报告开头用表格明确列出每一处替换及原因。

## 二、指标替换对照表（直接用于报告第一章）

| 原框架指标 | 适用性 | 银行替代口径 | 不适用原因 |
|---|---|---|---|
| 核心利润 = 营收 − 营业成本 − 税金 − 销售/管理/研发费用 − 利息费用 | ❌ 不适用 | **银行版核心利润** = 利息净收入 + 手续费及佣金净收入 − 业务及管理费 − 税金及附加 − 其他业务支出 | 银行无营业成本/销售费用/研发费用；利息支出已在"利息净收入"中扣除，再减一次会重复计算 |
| 核心利润获现率 = 经营现金流 ÷ 核心利润 | ❌ 不适用 | **存贷增速差**、**减值计提／拨备前利润** | 银行经营现金流由"吸收存款净增加""发放贷款净增加"主导，规模是净利润的数十倍，与盈利无关 |
| 流动比率 / 速动比率 | ❌ 不适用 | **资本充足率**、**存贷比**、**流动性覆盖率** | 银行无流动资产/流动负债划分；资产负债率天然 90%+，属行业属性 |
| 资产有息负债率 | ❌ 不适用 | **存款付息率**、**同业负债占比** | 负债主体是存款（原材料不是债务），计入有息负债会严重高估杠杆 |
| 应收账款 / 存货 / 现金周期 | ❌ 不适用 | **不良率**、**拨备覆盖率**、**拨贷比** | 银行的"存货"和"应收账款"都是贷款，周转概念不存在 |
| 资本支出／折旧摊销 | ⚠️ 弱适用 | 保留，但需说明银行固定资产占比极低（兴业 0.29%），该比率主要反映科技投入 | — |
| 三支柱两搅局 | ✅ 适用（改造） | 支柱一 利息净收入；支柱二 手续费及佣金净收入；支柱三 投资收益＋公允价值变动＋汇兑收益；**搅局 = 信用减值损失** | 逻辑完全成立，只是构成内容需替换 |
| 营业利润／利润总额 | ✅ 适用 | 直接沿用 | — |
| 利润积累占比 | ✅ 适用 | **（未分配利润 + 盈余公积 + 一般风险准备）÷ 归母权益** | 一般风险准备从净利润中提取，属利润积累性质，必须计入 |
| 未分配利润勾稽 | ✅ 适用 | 期末 = 期初 + 归母净利 − 提取盈余公积 − **提取一般风险准备** − 分配股利 | 银行独有"一般风险准备"提取项，漏掉会造成大额缺口 |

## 三、银行专属核心指标清单

这些指标在工商企业分析中不存在，但对银行是决定性的，**必须单独成章**：

| 指标 | 健康标准 | 获取途径 |
|---|---|---|
| 净息差 NIM | ≥ 1.80%（股份行）；趋势企稳为关键 | 公司年报／半年报"财务概要"，或 WebSearch |
| 不良贷款率 | ≤ 1.50%，股份行优 ≤ 1.10% | 年报、半年报摘要 |
| 拨备覆盖率 | ≥ 200%，警惕连续下降 | 同上 |
| 拨贷比 | ≥ 2.50% | 半年报披露，或用"拨备余额 ÷ 贷款"自算 |
| 核心一级资本充足率 | 系统重要性银行 ≈ 8.75%，缓冲 ≥ 1pp | 年报 |
| 资本充足率 / 一级资本充足率 | ≥ 12.50% / ≥ 9.75% | 年报 |
| 成本收入比 | ≤ 30% | 年报，或 业务及管理费 ÷ 营业收入 自算 |
| 存款付息率同比 | 下降为优 | 半年报（通常只披露变动 bp） |
| 存贷比 | ≤ 95% | 贷款 ÷ 存款 自算 |

**自算口径**（当公开数据源缺失时）：
- 简化净息差 = 利息净收入 ÷ 期初期末平均总资产。绝对值与公司披露的日均生息资产口径不可直接比较，但**趋势一致**，可用于十年序列。须在图表下方注明。
- 信用减值损失 = 营业支出 − 税金及附加 − 业务及管理费 − 其他业务支出。
- 拨备前利润 = 营业收入 − 税金及附加 − 业务及管理费 − 其他业务支出 = 营业利润 + 信用减值损失。
- 不良余额 = 贷款 × 不良率；拨备余额 = 贷款 × 拨贷比；拨备覆盖率 = 拨备余额 ÷ 不良余额。

## 四、银行特有的强勾稽验证（务必做）

**减值计提倒算验证**——这是银行版三表勾稽中强度最高的一项，务必写进报告：

1. 用利润表倒算：信用减值损失 = 营业支出 − 税金及附加 − 业务及管理费 − 其他业务支出
2. 与现金流量表间接法的「计提的资产减值准备」逐年比对
3. 兴业银行实测：**十年全部吻合，最大差异 0.01 亿元**；2026H1 倒算 325.12 亿与半年报披露值分毫不差

这项验证能一次性证明利润表与现金流量表的一致性，比制造业的间接法加总更有说服力。

**未分配利润勾稽**必须包含一般风险准备：
```
期末未分配利润 = 期初 + 归母净利 − 提取盈余公积 − 提取一般风险准备 − 分配股利 − 优先股/永续债股息
```
兴业的分配额倒算结果 = 现金分红 + 永续债利息，可与 `westock dividend` 记录交叉验证。

## 五、数据源注意事项

- **westock `finance --type income`** 对银行返回的字段是通用的（OperatingRevenue、NetProfit 等），**不含**利息净收入、中收、减值等银行科目 → 必须走新浪 F10 脚本补明细。
- **新浪 F10 银行科目命名**：`一、营业收入`、`利息净收入`、`手续费及佣金净收入`、`投资净收益`、`公允价值变动净收益`、`汇兑收益`、`二、营业支出`、`业务及管理费用`、`营业税金及附加`、`其他业务支出`、`发放贷款及垫款`、`客户存款(吸收存款)`、`归属于母公司股东的权益`、`一般风险准备`、`未分配利润`。
- **2019 年后"资产减值损失"科目在新浪数据里为空**（新准则改为信用减值损失，脚本未抓取到该行），必须用倒算补齐——倒算值可与现金流量表的「计提的资产减值准备」互验。
- **监管指标（不良率、拨备、资本充足率、净息差）westock 完全没有**，只能靠 WebSearch 年报／半年报，或东财 F10（银行类接口常返回"无 F10 资料"，不要浪费时间，直接 WebSearch）。

## 六、常见误判（血的教训）

1. **把银行经营现金流为负当成风险。** 正常。十年累计 −8,223 亿只是贷款净投放，必须在报告里明确否定这一读法。
2. **把资产负债率 91% 当成高杠杆风险。** 正常。招商 90.18%、浦发 91.92%。
3. **把"多提减值 + 覆盖率下降"当成造假。** 不是。这是存量不良出清快于拨备补提的真实信号，应判定为"风险抵补能力变薄"而非"财务异常"。
4. **忽略中收口径调整。** 兴业 2022→2023 年中收从 450.41 亿降至 277.55 亿（−38.4%），含口径调整因素。需在报告中说明"部分降幅来自口径变化"，但同口径趋势判断不受影响。
5. **用制造业的"现金周期/占款能力"夸奖银行。** 银行没有应付账款概念，存款不是占款。

## 八、收口方式

银行的唯一关键变量通常是**净息差能否企稳**（而非制造业的"营收拐点"）。原因是净息差同时决定了利息净收入、资产配置行为和减值压力，是多条风险链的公共上游——识别这类"同源性"并点明，是汇报价值最高的动作。
