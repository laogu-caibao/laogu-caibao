# 特殊行业适配指南（券商 / 保险 / 地产 / 重资产周期 / 轻资产）

> 触发条件：分析对象**不是**一般工商企业时，先按本文判断是否需要替换口径。
> 银行请先读 `bank-adaptation.md`（那是完整版，本文只做索引）。
> 通用原则：保留张新民框架的**逻辑内核**，替换不适用的指标，并在报告第一章前置「替换对照表」。

## 一、三步判断法（拿到报表先做这个）

1. **找缺失科目**——抓取后 grep 一下，如果下列科目**不存在**，说明框架不适用：
   `营业成本`、`存货`、`应收账款`、`销售费用`。缺任意一个都要警惕；全部缺 = 必须替换口径。
2. **找该行业真正的"主营"**——利润主要来自哪一项？把它定义为"支柱一"。
3. **列出会被误读的指标**——凡是用到缺失科目的指标（毛利率、现金周期、获现率等）都在报告里明确标注"不适用及原因"。

**绝对禁止**：明知口径不适用，却照抄制造业公式得出"风险"结论。这是本框架最常见的错误用法。

## 二、证券公司（如 600030、600837）

| 项目 | 处理 |
|---|---|
| 营业收入构成 | 手续费及佣金净收入（经纪/投行/资管）＋ 利息净收入（两融）＋ 投资收益 ＋ 公允价值变动 ＋ 汇兑 ＋ 其他业务收入 |
| 是否有"营业成本" | **无**。张新民核心利润公式直接套用会等于营收本身，毫无意义 |
| 替代核心口径 | **中介类业务利润** ≈ 手续费及佣金净收入 + 利息净收入 − 业务及管理费 − 税金及附加（剔除自营投资波动） |
| 三支柱改造 | 支柱一 手续费及佣金净收入；支柱二 利息净收入；支柱三 投资收益＋公允价值变动＋汇兑；搅局 = 信用减值损失 |
| 获现率 | **不适用**。经营现金流由自营投资、回购业务、客户保证金进出主导，与盈利无关 |
| 资产负债率 | **必须剔除代理买卖证券款**（客户资金是负债科目但不是券商的债）。用 `调整后权益乘数 =（总资产 − 代理买卖证券款）÷ 归母权益` |
| 关键专属指标 | 经纪/投行/资管收入占比、自营投资收入占比、两融余额与市占、杠杆率、**净资本/净资产**、风险覆盖率、流动性覆盖率 |
| 勾稽要点 | 同银行：信用减值损失倒算（营业支出 − 税金 − 管理费 − 其他业务支出）vs 间接法计提 |

**常见误判**：把"自营投资收益占比高"简单判为"不务正业"。券商自营是牌照内的正常业务，应看其波动率与风险敞口，而非有无。

## 三、保险公司（如 601318、601628）

| 项目 | 处理 |
|---|---|
| 营业收入 | 保费收入（已赚保费）＋ 投资收益 ＋ 公允价值变动 ＋ 其他业务收入 |
| 最大负债 | **保险责任准备金**（未到期责任准备金、未决赔款准备金、寿险责任准备金）。**不是有息负债**，计入杠杆会严重高估风险 |
| 资产负债率 | 不适用。改用**偿付能力充足率**（核心 ≥ 50%、综合 ≥ 100%，监管底线） |
| 三支柱改造 | 支柱一 **承保利润**（保费 − 赔付 − 手续费佣金 − 准备金提转差）；支柱二 投资收益；支柱三 公允价值变动＋汇兑＋其他收益 |
| 财险专属 | **综合成本率 = 赔付率 + 费用率**，≤ 100% 才有承保利润（这是财险最重要的单一指标） |
| 寿险专属 | **新业务价值 NBV、内含价值 EV、新业务价值率、13 个月继续率、退保率**。寿险当期利润受精算假设影响大，EV 比净利润更能反映价值 |
| 获现率 | 不适用。保费流入计入经营活动，天然为正且规模巨大，与"盈利质量"无关 |
| 关键投资指标 | 净投资收益率、总投资收益率、综合投资收益率；权益资产占比 |
| 勾稽要点 | 准备金提转差倒算；投资收益与资产负债表投资资产规模交叉验证 |

**常见误判**：用"利润下滑"判定基本面恶化。寿险利润高度依赖投资收益与折现率假设，必须同时看 NBV/EV 才能定性。

## 四、房地产开发（如 000002、600048）

| 项目 | 处理 |
|---|---|
| 营业收入 | 结转收入，**滞后销售 2—3 年**。当期营收不反映当期经营 |
| 合同负债（预收款） | 是负债不是收入，但它是**未来营收的先行指标**，必须单独跟踪 |
| 核心利润 | 需**加回资本化利息**。房企大量利息资本化计入存货，报表财务费用被低估，核心利润被高估 |
| 三道红线 | 剔除预收的资产负债率 ≤ 70%、净负债率 ≤ 100%、现金短债比 ≥ 1 |
| 关键专属指标 | 全口径销售金额与排名、权益销售比、土储货值与去化周期、**已售未结转货值**、拿地强度（拿地额/销售额）、融资成本 |
| 存货 | 主要是在建项目与土储，周转天数长达 3—5 年是行业属性，**不能**按制造业标准判"积压" |
| 现金流 | 经营现金流长期为负（拿地支出计入经营），**获现率不适用**；改看销售回款率 |
| 勾稽要点 | 合同负债增加额 vs 销售回款；存货增加 vs 拿地支出 |

## 五、重资产周期股（钢铁 / 水泥 / 化工 / 有色）

| 项目 | 处理 |
|---|---|
| 核心特征 | 折旧摊销占比高、盈利随价格周期大幅波动 |
| 资本支出/折旧 < 1 | **不必然**等于"停止扩张"，可能是周期底部的主动收缩。必须结合产量、价格、行业开工率判断 |
| 关键专属指标 | 吨毛利 / 价差（售价 − 单位成本）、产能利用率、行业库存、**经营性现金流 ÷ 折旧摊销**（现金覆盖折旧的能力） |
| 亏损年份 | 不要判定为"造假"或"失去盈利能力"。看的是周期位置的相对水平，不是绝对值 |
| 勾稽要点 | 在建工程转固节奏 vs 资本支出；减值计提是否集中在周期底部（"洗大澡"嫌疑） |

## 六、轻资产软件 / 服务 / IT（如 300496、300520）

| 项目 | 处理 |
|---|---|
| 无存货 | 毛利率计算仍成立（营业成本为人力与外购），但**现金周期不适用**（或仅看应收与应付两端） |
| 应收账款 | 政府与大客户项目型公司回款慢，应收周转天数是核心风险指标 |
| 研发费用资本化 | 资本化率上升会虚增利润与资产。**研发费用资本化率 = 开发支出增加额 ÷（研发费用 + 开发支出增加额）**，>30% 需警惕 |
| 股份支付 | 计入管理费用，会压制当期利润。分析时应单列 |
| 商誉 | 并购驱动型公司商誉高，减值是"搅局"的主要来源（科大国创 2020 年以来减值累计 8.53 亿，商誉从 5.79 亿减到 0.70 亿） |
| 关键专属指标 | 合同负债（预收）、经营性现金流/营收、人均创收、研发费用率、应收账款周转天数、商誉/净资产 |
| 现金流 | 人力成本为主、Q4 集中回款 → **必须用年度数据看趋势，单季度数据会严重误导** |

## 七、通用报告结构（特殊行业版）

| 章节 | 内容 |
|---|---|
| 〇、框架适配说明 | **必须前置**：逐项列出被替换的指标、替代口径、不适用原因 |
| 一、核心结论 | KPI 卡 + 中心论点 + 三条一级论据 + 同业对照 |
| 二、企业体检表 | 模块按行业调整（如银行加"资产质量"、券商加"杠杆与风控"、地产加"三道红线"） |
| 三、主营拆解 | 用行业专属口径重写"三支柱两搅局" |
| 四、不适用指标说明 | 明确写出哪些经典指标不能用、为什么（这是专业性的体现） |
| 五、三表勾稽验证 | 五项 + 行业专属强勾稽（银行：减值倒算） |
| 六、同业对照 | ≥3 家同类机构 |
| 七、风险与跟踪 | 分级风险 + 红黄绿看板 |

## 八、收口的关键变量（按行业）

| 行业 | 唯一关键变量（通常是） |
|---|---|
| 制造业 | 营业收入能否出现拐点 |
| 银行 | 净息差能否企稳 |
| 券商 | 市场成交额 + 自营投资收益率 |
| 保险 | NBV 增速（寿险）／综合成本率（财险） |
| 地产 | 销售金额与现金短债比 |
| 周期股 | 产品价差（售价 − 成本） |
| 软件服务 | 应收账款周转 + 合同负债增速 |
