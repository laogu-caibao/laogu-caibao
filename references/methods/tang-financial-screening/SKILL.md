# 唐朝财报排除法

## 这个 Skill 做什么

把唐朝《手把手教你读财报》的方法论变成可执行的八步流程，对一家上市公司给出**明确结论**。

三条核心理念：

1. **财报是用来排除企业的，不是用来证实的** —— 宁可错杀而少赚，也不能踩雷而亏本
2. **先看资产负债表，再看利润表，最后看现金流量表** —— 这是投资高手的阅读顺序
3. **每个疑问都要在附注里找答案** —— 企业必须披露却又不太想让你明白的东西，都在附注里
   （**已落实为每步的必查项**，见 `@references/notes-checklist.md` 与下文的附注核查表）

> ⚠️ **这不是通用财报框架。** `ROE>15% + 现金流/净利>1 + 低杠杆` 这套标准提炼自
> 消费类成熟企业，靠历史财务做**后置验证**。用它评估技术未定型的企业
> （固态电池、创新药早期、人形机器人），会把最优质的标的一键排除——
> 不是阈值不准，是**工具类型错了**。所以分析前必须先分型。

## ⚠️ 执行门禁（违反即本次分析无效）

**三个检查点，必须按顺序完成、并且把结果展示给用户之后，才能进入下一步。**

| 门禁 | 必须做到 | 没做到会怎样 |
|:--:|---|---|
| **G1 数据源** | 列出可选数据源，**用户已确认**（或明确接受默认值） | 不许开始取数 |
| **G2 分型** | 输出分型卡，**用户已确认**（或明确接受默认） | 不许进入八步 |
| **G3 范围** | 确认分析深度与报告期 | 不许输出报告 |

**门禁不是形式**：G1 决定取数路径，G2 决定全部阈值，G3 决定工作量。跳过任何一个，后续分析的前提都不成立——**结论再漂亮也是空中楼阁**。

### 🔴 跨 Skill 上下文不共享（最常见的违规借口）

若本次调用是从别的 skill 转过来的（例如「个股分析总入口」已经问过数据源、做过分型初判），
**本 Skill 看不到那些对话**。即便上文已经问过，仍必须执行 G1–G3。

可以用**简写确认**，但必须让用户看到、并有机会推翻：

```
沿用上文的判断，你确认一下：
  数据源：通达信 + AKShare（历史三年数据需 AKShare）
  分型：混合体 — 成熟盘 69.48% 走 A/B + 新兴盘 15.67% 走 D
  范围：完整八步，覆盖 2023–2026H1

回「确认」我立刻开始；想改哪条直接说。
```

> **禁止**以"上文已经问过了"为由直接跳过。省一次确认，可能让整份报告的立论基础出错——
> 尤其 G2 的分型选择，往往直接决定最终结论（A 型看绝对值 vs C 型看趋势，结论可能相反）。

## 一、开始前：确认数据源（必做，第一句就问）

**不要假设用户有什么数据源。** 开场先问，拿到答案再动手。

```
开始前确认一下数据源，你手上有哪些？（可多选）

  □ ① 通达信 MCP   ← 推荐。零配置，一次调用拿到行情 + PE/PB/ROE/现金流
  □ ② AKShare     ← 需本地装 Python 包。适合拉多年三表和同行批量对比
  □ ③ 财报 PDF     ← 你有年报文件，我直接解析附注
  □ ④ 我粘贴数据   ← 你已经整理好指标了
  □ ⑤ 都没有       ← 我用联网搜索兜底，但深度会打折

默认选 ①，说「默认」就行。
```

详细取数规范、各源能拿到什么、已知限制见 `@references/data-sources.md`。

**最小数据需求**（缺任一项先告诉用户，别硬跑）：

- [ ] 最近 **3 个完整年度** + 最新一期的三表数据
- [ ] 同行业 **2–4 家**可比公司指标
- [ ] 最新一期市值 / PE / PB

## 二、企业分型（必做，不可跳过）

> 这一步决定后面所有步骤的阈值与权重。

### 三问决策树

```
Q1 主营所处技术路线是否已收敛？
    判据：头部玩家路线是否一致 / 行业良率是否 >90% / 成本曲线是否可预测
    └─ 否（多路并行、良率<80%、头部成本差数倍）──────→ 【D 技术未定型】
    └─ 是 ↓
Q2 需求或价格是否强周期波动？
    判据：毛利率或产品单价峰谷差 >50% 且与宏观/商品周期同步
    └─ 是 ─────────────────────────────→ 【B 周期重资产型】
    └─ 否 ↓
Q3 是否处于放量/产能建设期？
    判据：营收增速 >25% 或 在建工程÷固定资产 >30%
    └─ 是 ─────────────────────────────→ 【C 成长扩张型】
    └─ 否 ─────────────────────────────→ 【A 成熟稳定型】
```

### 四型与唐朝框架的角色

| 分型 | 唐朝框架扮演什么 | 核心替换指标 |
|------|------------------|-------------|
| **A 成熟稳定型** | **选股框架**（找好公司，原版全量启用） | ROE 5年均值、现金流均值、PE/PEG |
| **B 周期重资产型** | **周期校正工具**（避免峰谷误判） | 跨周期 ROE、PB 分位、单位市值/重置成本 |
| **C 成长扩张型** | **排雷框架**（用来证伪，不作优选依据） | ROE 趋势、周转率、现金流缺口解释度 |
| **D 技术未定型** | **真实性审查**（只留与生命周期无关的造假检测） | 现金续航月数、技术里程碑、单位成本曲线 |

> 分型的完整参数表（各型启用/弃用哪些指标、排除线、打分矩阵）见
> `@references/company-archetypes.md`

### 混合体（勿强行归单一型）

新兴业务占 **10%–70%** 时分部拆算：

1. 按营收/毛利占比拆出「成熟盘」与「新兴盘」
2. **成熟盘走 A/B** → 得**底盘价值**（真实 ROE、现金流、合理估值）
3. **新兴盘走 D** → 得**期权价值**（投入确定、回报或有，可能为负）
4. **倒推市场定价**：市值 − 底盘价值 = 市场为期权支付的价格
5. ⚠️ **安全垫检验**：成熟盘自身就不达标 → 整个故事没有安全垫

### 分型输出卡（每份报告开头必写）

```
【企业分型】X 型（置信度：高/中/低）
判据：Q1={是/否，依据} | Q2={...} | Q3={...}
唐朝框架角色：选股框架 / 周期校正 / 排雷框架 / 真实性审查
本型启用指标：{列出}
本型弃用指标：{列出，并说明为何不适用}
本型排除线：{一句话}
```

## 三、确认分析范围（第 2 轮，也是最后一轮）

分型出来后，把初判给到用户并确认深度：

```
【{公司}】分型初判：{X 型}

想跑到哪一步？

  ① 完整八步   → 全流程 + 12 信号 + 杜邦 + 综合结论      ~30 min  ← 推荐
  ② 快速排雷   → 只跑红色信号扫描，看有没有硬伤          ~10 min
  ③ 指定步骤   → 你说跑到第几步

报告期默认覆盖最近 3 年 + 最新一期，要改就说。
说「按推荐来」我直接开始。
```

**交互三条铁律**：**最多 2 轮** · **必须有推荐项** · **必须可跳过**（用户说"你看着办"就按推荐执行）。

**跳过交互的例外**：用户已说全标的 + 方式（"用唐朝完整分析贵州茅台 2025 年报"）、
自动化任务调用、用户明说别问了。

**推荐调整**：D 型公司推荐 ①（技术未定型必须看全，否则容易漏掉造假信号）；
用户一次给多个代码时推荐 ②（先批量过筛再深挖）。

## 四、八步流程

```
第零步：企业分型 → 确定唐朝框架角色与各步阈值
第一步：鸟瞰三大表 → 浏览各科目，找出异常
第二步：资产负债表扫描 → 资产质量 + 负债结构 + 货币资金
第三步：利润表拆解 → 毛利率 + 营业利润 + 非经常性因素
第四步：现金流量表检验 → 经营现金流/净利 + 企业现金流肖像
第五步：杜邦分析 → ROE 三因子拆解（净利率×周转率×杠杆）
第六步：财务排雷 → 12 大红色信号逐一检验（按分型口径）
第七步：基数异常 + 机构预期对比
第八步：综合判断 → 排除/观察/关注（按分型打分矩阵）
```

逐步推进，**发现致命信号可直接排除，不必走完全流程**。

> 第一至七步的详细检查清单（每项标注适用分型）见 `@references/steps-1-7-checklist.md`

### ⚠️ 每一步都要查附注（硬性要求，不是可选项）

> **三张报表是结论，附注是证据。** 只看三表就下判断，等于只看判决书不看卷宗。

每完成一步，对照 `@references/notes-checklist.md` 核查该步的必查附注：

| 步骤 | 必查附注 | 特别留意 |
|:--:|---|---|
| 零 / 一 | 会计政策与估计变更、合并报表范围变更 | 🔴 改折旧年限 = 合法造假 |
| 二 | 货币资金**受限**、应收**账龄**、存货构成、**其他应收款**、在建工程、借款利率 | 🔴 其他应收款是"垃圾筐" |
| 三 | 营业收入**分部**、研发资本化率、投资收益、其他收益、减值明细 | 🔴 靠卖资产撑利润 |
| **四** | **现金流量表补充资料**（净利润 → 经营现金流调节表） | ⭐ **全份财报信息密度最高** |
| 五 | 分部资产与分部利润 | 可算分部 ROE |
| 六 | 关联方及关联交易、或有事项、资产负债表日后事项 | 🔴 利益输送主渠道 |
| 七 | 分部口径是否变更、非经常性损益明细 | 同比是否失真 |

**三条执行规则**：

1. **附注发现必须进报告，并标注来源**（如"附注七·4 应收账款"），让读者可复核
2. **拿不到附注 ≠ 可以跳过** —— 写进「数据缺口」章节，并在结论里**下调置信度**
3. **第四步的补充资料是重中之重** —— 净利润与经营现金流的差额全藏在那张调节表里；
   没看它就下"现金流背离"的结论是不可靠的

> 仅在结构化数据（如 AKShare 摘要）下工作时，附注天然缺失——
> 此时**必须在报告里明确列出"哪些附注没查到"**，不能假装这一步做过了。

### 横向对比（第三步与第六步都要用）

财务指标必须在同行中对比才有意义，核心目的是**区分"行业通病"还是"个体问题"**：
同行普遍存在可部分解释，仅目标公司一家异常则是红色信号（同��能管住你管不住）。

比什么：毛利率、应收/净利比、ROE、经营现金流/净利。
各指标的分型校正规则见 `@references/steps-1-7-checklist.md`

> **B 型**：对比必须同期（周期顶部人人高毛利，跨期比无意义）
> **D 型**：行业普遍亏损时横向对比退化为"比谁亏得少"，改用绝对指标（续航、里程碑、成本降幅）

### 第八步：综合判断

打分维度 = 通用 4 项（排雷结果、安全性、费用控制、毛利率趋势）+ 分型专属 3 项。

| 结论 | 条件 |
|---|---|
| **排除** | 总分 ≤ −0.3N（N=参与打分维度数），**或触发任一硬性排除线** |
| **继续观察** | −0.3N < 总分 < +0.35N |
| **值得关注** | 总分 ≥ +0.35N 且无红色信号 |

**硬性排除线（触发即排除，不看总分）**：

| 分型 | 排除线 |
|---|---|
| A | 5 年 ROE 均值 <15% / 现金流均值 <0.5 / 任一红色信号无法解释 |
| B | 跨周期 ROE 均值 <8% **且** PB >70% 分位 |
| C | 营收增长 + 毛利率下降 + 周转率下降**三者同时** / 连续 2 期现金流缺口扩大且收现比 <0.8 |
| D | 现金续航 <12 个月 / 里程碑连续 2 次跳票 / 大股东在里程碑前大额减持 |

**N 的计数规则**：N = 实际参与打分的维度数。某项因**数据不可得**判 N/A 时**不计入 N**，
且该项不得分——不要把 N/A 当 0 分，那会人为稀释总分。

> 例：D 型「单位成本曲线降幅」多数 A 股公司无公开数据，此时 N 由 9 降为 8，
> 排除阈值由 −2.7 变为 −2.4。

⚠️ **「值得关注」有附加条件：无红色信号。** 即使总分达标，
只要排雷出现 ≥1 个红色信号，**降一档为「继续观察」**。

> 实测案例：某标的通用 +1 / 成熟盘 A 型 −2 / 新兴盘 D 型 0，总分 −1（N=9，阈值 −2.7），
> 按总分应为「继续观察」；但 A 型两条排除线触发（5 年 ROE 均值 −12.61%、现金流均值 0.013），
> **最终判排除**。总分与排除线冲突时，**排除线优先**。

完整打分矩阵见 `@references/company-archetypes.md`

## 五、输出格式

**报告骨架**：复制 `templates/report-skeleton.md` 后逐节填充。
不适用的章节**保留标题并注明原因，不要直接删** —— 保留痕迹能让读者知道这一步被考虑过。

13 项必含内容：分型卡、三年+最新期数据总览、同行对比表、资产负债表信号、
利润表拆解、现金流质量、杜邦分析、12 信号排雷（按分型口径，标注适用/弃用）、
非经常性剥离、基数异常检验、混合体拆分结论（若为混合体）、综合判断与得分明细、
后续跟踪指标。

> ⚠️ **若为混合体，「混合体拆分」是全篇的核心章节，不是配菜。**
> "市值 − 底盘价值 = 市场为期权支付了多少钱" 这句往往比任何单项指标都更有冲击力，
> 必须算出具体数字并在结论复述里引用。切勿一笔带过。

**输出位置**：默认在当前工作目录下生成 Markdown 文件，
文件名 `{公司名}_{代码}_{报告期}_唐朝财报分析.md`。
**不要假设用户有特定的笔记库或目录结构** —— 如果用户指定了输出路径，用他的。

### 语言风格

- 简洁直接，拒绝"精彩纷呈""令人瞩目"这类形容词
- 每个结论必须有数字支撑
- 区分**事实**与**推断**，推断处标注不确定性
- 敢于给出"排除"结论，但必须说清是"不符合标准"还是"有造假嫌疑"——**这是两回事**
- A 股涨标红、跌标绿
