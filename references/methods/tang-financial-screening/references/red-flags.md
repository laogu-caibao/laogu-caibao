# 12大红色信号与常见造假手法

> 源自唐朝《手把手教你读财报》第八章"欺诈与反欺诈"及全书分析经验
> 核心原则："事反必妖"——突然出奇得好或突然出奇得坏，都需要探索解释

> ⚠️ **v2.0 使用前提**：本文件的 12 大信号默认口径是**成熟企业**。
> 使用前必须先完成「第零步：企业分型」，由分型决定每条信号是**启用 / 降级 / 弃用**：
> - **全型适用**（与生命周期无关，任何时候都成立）：#1 存贷双高、#4 在建工程、#5 其他应收款、#6 长期待摊、#7 商誉、#10 资产减值
> - **需按分型调整**：#2 应收、#3 存货+毛利率背离、#8 毛利率、#9 销管费用率、#12 现金流背离
> - **D 型弃用**：#8 毛利率异常、#11 营业外收入占比、#12 现金流背离
>
> 完整调整规则见 `@references/company-archetypes.md`，带分型标注的信号总表见 `@references/steps-1-7-checklist.md` 第六步。

## 一、资产负债表信号（7个）

### 信号1：存贷双高

**表现：** 货币资金充裕 + 大量有息甚至高息负债

**可能原因：**
- 货币资金虚构（报表日前临时回账）
- 货币资金被冻结或被大股东占用
- 借来的钱实际上没用于经营

**唐朝原话：** "自己账上货币资金不少，却又在高息借债，造假的可能性就非常高"

**检验方法：**
```
现金及现金等价物 ÷ 有息负债 < 1 → 危险
筹资活动中的利息支出 vs 有息负债 → 借款利率是否异常偏高
```

---

### 信号2：应收账款异常

**表现：**
- 增速远超同期营收增速
- 占收入比例大，一年以上应收款超三成
- 回款突然有大笔回收（之前长期挂账）
- 坏账计提标准显著低于同行
- 不公布账龄结构，只按固定比例计提

**可能手法：**
1. 虚构交易 → 应收增加
2. 放宽信用政策促进短期收入
3. 提前确认收入
4. 现金冲销旧应收 → 通过其他科目转出

**案例：** 四川长虹45亿应收款产生37亿坏账，把多年累积"利润"一次赔完

---

### 信号3：存货+毛利率背离

**表现：** 存货周转率下降 + 毛利率上升

**这是唐朝发现的最关键造假信号。**

**逻辑链条：**
1. 存货周转率下降 = 产品滞销
2. 滞销本应导致降价促销或增加费用 → 毛利率应该下降
3. 毛利率反升 = 违背商业常识

**两种造假路径：**
- 虚构采购流出资金 → 存货虚增 → 存货周转率下降
- 加大生产摊薄固定成本 → 存货增加 + 单位成本降低 → 毛利率上升

---

### 信号4：在建工程异常

**表现：**
- 与生产经营规模不相适应地大幅增加
- 迟迟不转固定资产
- 不断追加资金
- 转固后不久又需大修或技改

**可能手法：**
1. 通过在建工程采购将资金转出 → 以收入形式流回虚增利润
2. 将本应从利润表扣除的费用打入在建工程成本
3. 在建工程本身是虚构的

**检验方法：** 查看当初募集资金承诺的项目，是否在预定时间内转固并产生效益

---

### 信号5：其他应收款过大

**唐朝原话：** "其他应收款就是一个垃圾筐"

**表现：** 占总资产比例>5%

**可能用途：**
- 隐藏短期投资，截留投资收益
- 转移资金，大股东占用
- 私设小金库
- 隐藏利润或费用

**反面指标：** 优秀公司"其他应收款"和"其他应付款"极小甚至为零

---

### 信号6：长期待摊费用大增

**含义：** 不恰当地使用费用资本化手段

**检验：** 查看明细构成，看是否将本应计入当期费用的支出资本化

---

### 信号7：商誉过高

**表现：** 商誉占净资产>30%且频繁收购

**风险：**
1. 收购时做高商誉 → 减少可辨认资产折旧 → 虚增利润
2. 需要时按需减值 → "进可攻退可守"
3. 可能是和卖家合作，通过收购将投资活动现金流转化为经营活动现金流

**处理建议：** 尝试将商誉还原为资产，按折旧规则重新评估公司价值

---

## 二、利润表信号（4个）

### 信号8：毛利率异常

**表现：**
- 显著高于同行且无合理解释
- 同比大幅波动

**检验步骤：**
1. 是否是销售单价提升？→ 观察市场
2. 是否是原材料成本下降？→ 对比同行
3. 是否是产品结构变化？→ 查看收入构成
4. 以上都不是 → 可能操纵财报

---

### 信号9：销管费用率骤降

**表现：** 大幅低于同行水平，同比大幅下降

**可能手法：**
1. 将费用推迟至未来（延长摊销、推迟计提）
2. 将费用资本化（计入在建工程/无形资产）
3. 掩盖成本（少计原材料成本、少计财务费用）
4. 新管理层上任时"洗大澡"后的低基数效应

---

### 信号10：资产减值大增（洗大澡）

**表现：** 资产减值损失同比大增

**检验：** 如果按上期减值水平算，利润同比波动并不大 → 故意做低基数

**两种动机：**
1. 毁尸灭迹 → 冲掉以前虚增的利润（如某公司盈利一年亏损一年循环）
2. 美化未来 → 新管理层做低当期，轻装上阵彰显"战绩"

**证监会特别警告：**
- 期末对欠款坏账、存货跌价等估计不足
- 推迟在建工程转固时间
- 推迟正常经营管理所需费用开支

---

### 信号11：营业外收入/其他业务收入占比高

**表现：** 利润主要来自偶然的营业外收入，且多年如此

**可能手法：**
- 在"主营业务"和"其他业务"之间随意划转
- 将非营利性交易确认为收入
- 关联交易显失公平

---

## 三、现金流量表信号（1个）

### 信号12：经营现金流与利润长期背离

**表现：** 经营现金流净额持续多年<净利润

**含义：** 企业生意做得越大，日子越难过

**排查方向：**
- 赊销卖货？→ 验证应收账款
- 存货积压？→ 验证存货变化
- 预付款大增？→ 验证预付款

---

## 四、常见操纵手法分类

### 操纵收入（最常见）

| 手法 | 具体操作 |
|------|----------|
| 虚构收入 | 空壳公司虚假交易、虚增成交金额 |
| 夸大收入 | 出售资产转为营业收入、互换贸易 |
| 提前确认收入 | 多年服务一次性确认、完工百分比超实际 |

### 操纵费用

| 手法 | 具体操作 |
|------|----------|
| 虚减费用 | 延长折旧、漠视坏账、费用资本化、推迟转固 |
| 掩盖成本 | 少计原材料、少计财务费用、少计销管费用 |
| 洗大澡 | 注销资产、大额计提减值、将经常性费用归入一次性费用 |

### 操纵现金流（目标：美化经营活动现金流）

| 手法 | 具体操作 |
|------|----------|
| 增加经营现金流入 | 收购公司获得经营现金流入、出售子公司时保留应收账款、存货抵押转为"销售" |
| 减少经营现金流出 | 融资租赁替代经营租赁、用承兑汇票采购 |
| 一次性美化 | 打折出售应收款、高额折扣刺激提前回款、拖欠供应商 |

## 五、财报以外的危险信号

| 信号 | 含义 |
|------|------|
| 无法按时发布财报 | 可能财务问题严重 |
| 更换会计师事务所（尤其多次更换） | 审计师不愿配合 |
| 独立董事集体辞职 | 知情者回避 |
| 大股东持续大量减持 | 内部人看空 |
| 财务总监更换频繁 | 可能因财务问题被逼走 |
| 供应商/客户可疑 | 虚构交易对象的特征 |
| 频繁跨行业收购，主要用股票支付 | 利用高估值股票做收购游戏 |
