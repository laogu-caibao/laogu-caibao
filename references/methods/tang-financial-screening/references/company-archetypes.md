# 企业分型与差异化评估参数

> 本文件解决一个根本问题：**唐朝框架不是通用框架，它对企业类型有隐含假设。**
> 用同一套阈值评估茅台和一家固态电解质公司，等于用体温计量血压。

---

## 一、唐朝框架的三个隐含假设（失效边界）

| # | 隐含假设 | 何时成立 | 何时失效 |
|---|---------|---------|---------|
| 1 | **历史财务记录对未来有预测力** | 技术路线与需求结构稳定 | 技术未收敛、商业模式未跑通时，历史数据与未来相关性趋近于零 |
| 2 | **权责发生制的偏差主要来自人为操纵** | 成熟经营、maintain 稳态 | 导入期企业的偏差大量来自技术爬坡本身（备货、账期、良率损失） |
| 3 | **好生意 = 高ROE + 强现金流 + 低杠杆** | 轻资产、无需前置重投入 | 需要前置资本开支/研发沉淀的产业，这条会把最优质标的全筛掉 |

**结论**：假设 1 决定唐朝框架能不能用来**优选**；假设 2 决定 12 大红色信号里哪些还成立；假设 3 决定 ROE/现金流阈值能不能直接用。

---

## 二、分型决策树（第零步必做）

```
Q1 主营所处技术路线是否已收敛？
    ├─ 判据：头部玩家路线是否一致 / 行业良率是否 >90% / 成本曲线是否可预测
    ├─ 否（多路并行、良率<80%、头部成本差数倍）──────────────→ 【D 技术未定型】
    └─ 是 ↓

Q2 需求或价格是否强周期波动？
    ├─ 判据：毛利率或产品单价峰谷差 >50% 且与宏观/商品周期同步
    ├─ 是 ────────────────────────────────────→ 【B 周期重资产型】
    └─ 否 ↓

Q3 是否处于放量/产能建设期？
    ├─ 判据：营收增速 >25% 或 在建工程÷固定资产 >30%
    ├─ 是 ────────────────────────────────────→ 【C 成长扩张型】
    └─ 否 ────────────────────────────────────→ 【A 成熟稳定型】
```

**边界处理**：
- 三问都无法判断 → 分型置信度标"低"，按较保守的一档（往 D/C 靠）执行
- 混合体（见第五节）→ 分部拆算，不强行归单一型

## 三、四型差异化参数表

### A 型：成熟稳定型（唐朝原版全量启用）

**典型**：白酒、家电、公用事业、成熟消费

| 步骤 | 处理方式 |
|------|---------|
| ROE | 5 年均值 >15%，且近 3 年无一年 <10%（**看均值不看单年**） |
| 现金流 | 经营现金流÷净利，**5 年均值 >0.8**（唐朝原文每年>1 过严，平滑掉单年扰动） |
| 杜邦 | 三因子拆解 + 盈利模式判断有效 |
| 毛利率 | 与同行横向对比有效 |
| 12 大信号 | **全部启用** |
| 估值 | PE + PEG + 股息率，三者交叉 |
| 排除线 | 任一红色信号无法合理解释 / 5年ROE均值<15% / 现金流均值<0.5 |

---

### B 型：周期重资产型（唐朝需做周期校正）

**典型**：锂钴、铜、化工、面板、航运、水泥

| 步骤 | 处理方式 |
|------|---------|
| ROE | **改用跨周期均值**（至少覆盖一个完整周期，5–7 年）。单年 ROE 不设 15% 门槛——周期底部 ROE 为负是常态 |
| 补充指标 | 单位市值（吨市值/产能市值）、重置成本法、PB 历史分位 |
| 现金流 | 看**全周期累计**，不看单年。周期底部的负现金流不代表经营恶化 |
| 毛利率 | 与同行对比**必须同期**。跨期比无意义（周期顶部人人高毛利） |
| 12 信号改造 | **#3 存货+毛利率背离 → 降级为黄色**（周期底部备货属正常，需结合产品价格判断）；**#1 存贷双高 保留**（与周期无关）；**#8 毛利率异常 → 需周期位置校正后再判** |
| 估值 | **PB + 单位市值 + 常态盈利×周期中位 PE**。**禁用当期 PE**——周期顶部 PE 最低，恰恰最危险 |
| 排除线 | 跨周期 ROE 均值 <8% **且** PB 处于历史 70% 分位以上 |

---

### C 型：成长扩张型（唐朝降级为排雷工具，不用于优选）

**典型**：产能爬坡期的制造、渠道扩张期的消费、放量中的设备

| 步骤 | 处理方式 |
|------|---------|
| ROE | 放宽至 >10% 或**不设绝对门槛**——改看 ROE 趋势向上 + 周转率不恶化 |
| 现金流 | 允许经营现金流÷净利 <1，但**必须满足两条**：<br>① 缺口能被营运资本明细完整解释（应收/存货/应付变动逐项可追溯，解释度 >80%）<br>② 缺口扩大速度 < 营收增速 |
| 现金流红线 | **连续 2 期缺口扩大 且 销售收现比 <0.8 → 排除** |
| 杜邦 | 重点看**周转率是否随规模下滑**（规模不经济预警），这是成长股最隐蔽的死法 |
| 12 信号改造 | **#2 应收异常 → 必须与同行同期对比 + 看账龄结构**（1 年以内占比），不能只看增速；**#12 现金流背离 → 从红线降为"黄色 + 必查明细"** |
| 估值 | PEG（用未来 2 年增速，须交叉验证）+ 单客户/单产品经济模型 |
| 排除线 | **营收增长 + 毛利率下降 + 周转率下降 三者同时出现**（增长既不赚钱也不高效） |

---

### D 型：技术未定型（唐朝仅保留造假检测，其余全部弃用）

**典型**：固态电解质、人形机器人、脑机接口、创新药早期

| 步骤 | 处理方式 |
|------|---------|
| ROE | **弃用**（分母为负或趋近于零，指标无意义） |
| PE/PEG/现金流比率 | **全部弃用** |
| **替代核心三问** | **① 现金续航** =（货币资金+交易性金融资产）÷ 月均经营现金净流出<br>　　<12 个月 → 红色；12–18 个月 → 黄色；>18 个月 → 通过<br>**② 技术里程碑** = 中试 → 客户验证 → 量产订单，处于哪一档？有无**第三方**验证（客户公告、装车/装机、送样检测报告、中标）<br>**③ 单位经济模型是否收敛** = 单价/成本曲线年度降幅。连续 2 年不降 → 证伪信号 |
| 唐朝保留项 | **仅保留与生命周期无关的造假检测**：<br>#1 存贷双高、#5 其他应收款、#7 商誉、#4 在建工程异常 —— 这四条任何时候都成立 |
| 唐朝弃用项 | #8 毛利率异常（无同行可比）、#11 营业外收入占比（早期政府补助占比高属正常）、#12 现金流背离（必然为负）、#3 存货+毛利率背离（备货爬坡常态） |
| 估值 | **期权思维**：Σ（里程碑达成概率 × 该情形下市值）折现；或按单 GWh / 单吨产能价值对照同业 |
| 排除线 | 现金续航 <12 个月 **或** 里程碑连续 2 次跳票 **或** 大股东在里程碑达成前大额减持 |
| 额外必查 | 股东户数变化（暴增 = 筹码向散户派发）、融券余额分位、研报覆盖度突变 |

## 四、分型输出卡模板（每份报告开头必写）

```
【企业分型】X 型（置信度：高 / 中 / 低）

判据：
  Q1 技术是否定型 = 是/否 → 依据：{头部路线是否一致、良率水平、成本曲线}
  Q2 是否强周期   = 是/否 → 依据：{毛利率/单价峰谷差、与宏观同步性}
  Q3 是否放量期   = 是/否 → 依据：{营收增速、在建工程÷固定资产}

唐朝框架角色：选股框架 / 周期校正 / 排雷框架 / 真实性审查
本型启用指标：{列出}
本型弃用指标：{列出，并说明为何不适用}
本型排除线：{一句话}
```

## 五、混合体处理（关键，勿强行归单一型）

**识别**：公司同时存在成熟业务与新兴业务，且新兴业务占比 >10% 但 <70%。

**典型案例**：光华科技（002741）
- PCB 化学品占营收 **69.48%**（成熟业务，AI 服务器 PCB 周期）
- 锂电池材料占营收 **15.67%**（新兴业务，+375% 但绝对额仅 3.52 亿）
- 市场按"固态电池标的"给到 86.8 倍 PE(TTM)

**处理流程**：

1. **分部拆算** — 按营收/毛利占比拆出「成熟盘」与「新兴盘」
2. **成熟盘走 A/B 框架** — 算它真实的 ROE、现金流、合理估值 → 得到**底盘价值**
3. **新兴盘走 D 框架** — 算投入强度、里程碑、现金续航 → 得到**期权价值**（可能为负，因为投入是确定的、回报是或有的）
4. **倒推市场定价** — 市值 − 底盘价值 = 市场为期权支付的价格，判断贵贱
5. **安全垫检验** — ⚠️ **成熟盘若自身就不达标，整个故事没有安全垫**。光华正是此情形：成熟盘 ROE 从未到 15%、经营现金流 −2.41 亿，新兴盘占比又不足以解释估值

**报告必须写明**：`成熟盘占 X%（A/B 框架） + 新兴盘占 Y%（D 框架） + 市场定价隐含假设 Z`

## 六、一句话总结

> 唐朝框架不是"一套标准"，而是**一套造假检测器 + 一套成熟企业优选器**。
> - 对 A 型：它是**选股框架**（用来找好公司）
> - 对 B 型：它是**周期校正工具**（用来避免峰谷误判）
> - 对 C 型：它是**排雷框架**（用来证伪，不当优选依据）
> - 对 D 型：它只剩**真实性审查**（只保留与生命周期无关的那几条）
>
> 用错角色，比不用更危险——因为它会给出看起来很专业、实则系统性偏差的结论。
