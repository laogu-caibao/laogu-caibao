# 附注核查清单

> 唐朝：**"每个疑问都要在附注里找答案——企业必须披露却又不太想让你明白的东西，都在附注里。"**
>
> 三张报表是**结论**，附注是**证据**。只看三表就下判断，等于只看判决书不看卷宗。
> 本清单按八步流程组织，每步列出**必查**的附注科目与危险信号。

## 使用方式

1. 有财报 PDF 时：`python3 scripts/parse_report.py <pdf> --keyword "应收账款" "存货" -o out.txt`
2. 只有结构化数据时：优先用 `stock_financial_abstract` 拿汇总，
   **但汇总口径看不到附注**，此时在「数据缺口」里明确列出哪些附注没查到
3. **拿不到附注 ≠ 可以跳过**：写进报告的数据缺口章节，并在结论里下调置信度

---

## 第零步 / 第一步：鸟瞰

| 必查附注 | 看什么 | 危险信号 |
|---|---|---|
| **会计政策与会计估计变更** | 本期是否变更？变更理由？影响金额？ | 🔴 频繁变更、理由含糊、影响金额巨大 |
| **重要会计估计** | 折旧年限、坏账计提比例、质保金率是否合理 | 🔴 显著宽松于同行（等于提前确认利润） |
| **合并报表范围变更** | 新增/减少了哪些子公司 | 🔴 年底突击并表或剥离（调节营收与利润） |

> 唐朝把「会计政策变更」列为**第一号警讯**：改一个折旧年限，利润就能凭空多出几千万，
> 而这一切完全"合法"。

---

## 第二步：资产负债表扫描

| 必查附注 | 看什么 | 危险信号 |
|---|---|---|
| **货币资金** | **受限资金**（保证金、质押、冻结、专户）有多少 | 🔴 受限占比高 → 表面现金充裕实际不能动，可解释"存贷双高" |
| **应收账款（账龄）** | 1 年内 / 1–2 年 / 2–3 年 / 3 年以上分布 | 🔴 长账龄占比上升、坏账计提比例低于同行 |
| **应收账款（客户）** | 前五大客户集中度、是否关联方 | 🔴 高度集中 + 关联方 = 收入真实性存疑 |
| **存货** | 原材料/在产品/库存商品/发出商品构成 + 跌价准备 | 🔴 库存商品激增（滞销）或跌价准备计提不足 |
| **其他应收款** | 按款项性质分类：押金、备用金、**关联方拆借** | 🔴 **唐朝称其为"垃圾筐"**，关联方占款常藏这里 |
| **长期股权投资** | 被投单位明细、持股比例、本期损益 | 🔴 大量亏损子公司、或参股公司需体外输血 |
| **在建工程** | 项目进度、预算、利息资本化金额 | 🔴 长期挂账不转固（少提折旧、虚增利润） |
| **商誉** | 资产组构成、减值测试的关键假设 | 🔴 假设过于乐观（增长率、折现率） |
| **短期借款 / 长期借款** | 借款行、利率、担保方式、到期日 | 🔴 利率显著高于同行（信用资质差）、短贷长用 |
| **无形资产** | 土地使用权/专利/非专利技术的构成与摊销年限 | 🔴 摊销年限超长（虚增利润） |

## 第三步：利润表拆解

| 必查附注 | 看什么 | 危险信号 |
|---|---|---|
| **营业收入（分部）** | **分产品 / 分地区 / 分季度** 的收入与毛利率 | 🟡 混合体拆算的**唯一数据来源**，缺了就无法分部估值 |
| **营业成本** | 成本构成（料/工/费） | 🔴 与营收增速不匹配 |
| **研发费用** | **资本化 vs 费用化** 的比例 | 🔴 资本化率突然升高（把费用变资产，虚增利润） |
| **销售费用 / 管理费用** | 明细科目（职工薪酬、折旧摊销、办公费…） | 🔴 某项异常增长 |
| **资产减值损失** | 计提明细（存货跌价、固定资产、商誉） | 🔴 一次性大额计提（**"洗大澡"**，为来年做低基数） |
| **信用减值损失** | 应收坏账计提与转回 | 🔴 大额转回（反方向调节利润） |
| **投资收益** | 构成：处置收益 vs 持有收益 | 🔴 **靠卖资产撑利润**（处置收益不可持续） |
| **其他收益** | 政府补助金额与性质 | 🔴 补助占利润比重高（主业不造血） |
| **营业外收入 / 支出** | 诉讼赔偿、罚款、捐赠、非流动资产毁损 | 🔴 大额诉讼计提（或有负债显性化） |

## 第四步：现金流量表检验 ⭐ 最重要

| 必查附注 | 看什么 | 为什么关键 |
|---|---|---|
| **现金流量表补充资料**（将净利润调节为经营活动现金流量） | 折旧摊销、减值准备、财务费用、投资收益、**存货的减少、经营性应收项目的减少、经营性应付项目的增加** | **这是全份财报信息密度最高的一张表**。它直接回答："净利润和经营现金流为什么差这么多？" |

**怎么用**：

```
净利润                          {A}
+ 折旧摊销                       {B}   ← 非现金支出，加回
+ 资产减值准备                   {C}
+ 财务费用（利息）               {D}
− 投资收益                       {E}   ← 若为正要扣除（不属于经营）
− 存货的增加                     {F}   ← 现金被存货占用
− 经营性应收项目的增加           {G}   ← 现金被客户占用
+ 经营性应付项目的增加           {H}   ← 占用上游资金
= 经营活动产生的现金流量净额     {I}
```

**判读**：

- `F + G − H` 若为正且巨大 → **利润都变成了存货和应收账款，没有变成现金**
- 若 `A` 为正、`I` 为负，且主因是 `G`（应收暴增）→ 增收不增现，回款出问题
- 若主因是 `F`（存货暴增）→ 备货失误或滞销
- 若 `H` 大幅增加 → 在占用上游资金维持运转（**议价力或现金流紧张的信号**）

> 唐朝："经营活动现金流与净利润的差额，全部藏在这张表的变化里。不看它，你永远不知道钱去哪了。"

| 另查 | 看什么 |
|---|---|
| **收到/支付的其他与经营活动有关的现金** | 大额往来款、关联方资金拆借 |
| **取得借款收到的现金 / 偿还债务支付的现金** | 借新还旧的规模与频率 |

## 第五步：杜邦分析

| 必查附注 | 看什么 |
|---|---|
| **分部报告（资产与负债）** | 各业务板块的资产总额 → 可计算**分部 ROE**，识别哪个板块在毁灭价值 |
| **分部报告（利润）** | 各板块营业利润 → 识别利润的真实来源 |

> 混合体案例：整体 ROE 难看，但若新兴板块分部资产极小、亏损可控，
> 说明亏损主要来自成熟板块——**归因完全不同，对策也完全不同**。

## 第六步：财务排雷

| 必查附注 | 看什么 | 危险信号 |
|---|---|---|
| **关联方及关联交易** | 关联采购/销售金额、定价政策、资金拆借、担保 | 🔴 大额关联销售（虚增收入）、无偿占用资金（利益输送） |
| **或有事项** | 未决诉讼、对外担保、债务重组、承诺 | 🔴 大额担保（或有负债随时变实） |
| **资产负债表日后事项** | 期后重大投资、诉讼进展、股利分配 | 🔴 期后暴雷 |
| **股份支付** | 股权激励费用摊销 | 🟡 会影响费用率的可比性 |
| **其他综合收益** | 其他综合收益的构成 | 🟡 是否存在大额浮亏 |

## 第七步：基数异常

| 必查附注 | 看什么 |
|---|---|
| **分部信息的历史口径** | 分部划分标准是否变更过 → 同比会失真 |
| **非经常性损益明细表** | 逐项列出，计算扣除后的真实盈利 |
| **会计政策变更的追溯调整** | 上年同期数是否被重述 |

## 唐朝的三个"附注必杀技"

### 1. 其他应收款 —— 垃圾筐

正常情况下其他应收款应该很小（占总资产 <1%）。**一旦它变大，先怀疑关联方占款。**

```
其他应收款突然增加
  → 查附注的款项性质分类
  → 若主要是"关联方往来""资金拆借"
  → 🔴 大股东在占用上市公司资金
```

### 2. 会计政策与估计变更 —— 合法造假

```
折旧年限从 10 年改成 15 年 → 每年折旧减少 → 利润凭空增加
坏账计提比例从 5% 改成 3% → 减值减少 → 利润凭空增加
```

这些**完全合规**，但本质是把明天的利润挪到今天。看到变更，必须算影响金额。

### 3. 补充资料 —— 照妖镜

三表可以修饰，**现金流量表补充资料很难修饰**——它要求把净利润和经营现金流之间的每一个桥梁科目都摊开。

想判断一家公司的利润是"真赚"还是"账面赚"，看这一张表就够了。

## 写在报告里

附注发现必须进报告，且**标注来源是哪一条附注**：

```markdown
| 发现 | 附注来源 | 判读 |
|---|---|---|
| 货币资金 5.79 亿中受限 1.2 亿（保证金+质押） | 附注七·1 货币资金 | 可动用现金仅 4.59 亿，存贷双高部分可解释 |
| 应收账款 3 年以上账龄占比从 8% 升至 15% | 附注七·4 应收账款 | 回款质量恶化，销售收现比 0.651 得到印证 |
| 现金流量表补充资料：经营性应收增加 −3.43 亿 | 附注七·78(1) | 现金流为负的主因是应收占用，非虚构收入 |
```

**拿不到附注时**（只有结构化数据）：

```markdown
**数据缺口**：本期未获取财报附注，以下项目无法验证——
货币资金受限金额、应收账款账龄结构、存货构成、关联交易、或有事项。
上述缺口会使「存贷双高」与「应收质量」两项的判定置信度下降，结论需谨慎看待。
```
