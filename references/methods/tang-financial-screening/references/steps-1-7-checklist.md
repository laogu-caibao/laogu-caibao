# 第一至七步详细检查清单

> 由 SKILL.md 主流程调用。执行到某一步时按需读取本文件对应章节。
> ⚠️ 每一步的**启用/改造/弃用**由企业分型决定，见 `@references/company-archetypes.md`。

## 第一步：鸟瞰三大表

### 方法论（唐朝四步法之第一步）

快速浏览资产负债表和利润表各科目，关注有无异常。

### 资产负债表关注项

**资产端（重点关注）：**
- 应收账款、应收票据、其他应收款 → 是否大幅增长（超过营收增速）？
- 预付款项、长期待摊费用 → 是否异常放大？
- 存货 → 是否增速远超营业成本增速？
- 在建工程 → 是否迟迟不转固定资产？
- 商誉 → 占净资产比例是否过高？
- 固定资产 → 是否出现异常减值或大修？

**负债端（重点关注）：**
- 应付票据、应付账款 → 大幅增加（可能是拖欠供应商，也可能是议价能力增强）
- 其他应付款 → 是否异常增大？
- 短期借款、长期借款 → 是否大幅增加？
- 有息负债 vs 货币资金 → 是否出现"存贷双高"？

### 利润表关注项

- 营业利润率 → 是否大幅变化？
- 公允价值变动收益 + 投资收益 + 资产减值损失 三者之和 → 占营业利润比例是否剧变？
- 营业利润与净利润比例 → 是否保持基本稳定？（扣除非经常性因素后）
- 其他业务收入 → 占营收比例是否突然大幅提升？

**以上科目若没有异常，进入下一步；反之，必须去附注中寻找解释。不能获得完整可信解释的，直接排除。**

> **D 型（技术未定型）提醒**：本步的"异常"阈值需大幅放宽——应收高、存货高、亏损都是爬坡常态，只保留"无法解释的异常"才追查。

## 第二步：资产负债表深度扫描

### 方法论

> "经验丰富的投资者，首先看的报表一定是资产负债表。" —— 唐朝

### 2.1 货币资金分析

**唐朝核心原则：货币资金需要与短期债务及经营需要相匹配。**

**四种危险信号（出现任一需高度警惕）：**
1. 货币资金余额 << 短期负债 → 短期偿债危机
2. 货币资金充裕，却借了很多有息甚至高息负债 → 资金可能是虚构或被大股东占用
3. 定期存款很多、其他货币资金很多，但流动资金严重缺乏 → 资金受限
4. 其他货币资金数额巨大，却没有合理解释 → 可能是大股东占用的过路资金

**安全标准（唐朝推荐）：**
```
现金及现金等价物 ÷ 有息负债 ≥ 1
或适度放宽：
(货币资金 + 金融资产净值) ÷ 有息负债 ≥ 1
```

> **D 型改造**：本指标升级为**核心指标**——改用「现金续航月数」=（货币资金+交易性金融资产）÷ 月均经营现金净流出。<12 个月红色，12–18 个月黄色。

### 2.2 经营相关资产

**应收账款（重点中的重点）：**

| 信号 | 含义 |
|------|------|
| 应收大幅增长超过营收增速 | 放宽信用政策 / 提前确认收入 / 虚构收入 |
| 应收账款占收入比例大，且一年以上超三成 | 收入真实性存疑 |
| 应收非常低（与商业模式不符） | 可能收入造假（如蓝田股份案例） |
| 应收账款突然有大笔回收 | 可能是用现金冲账再通过其他科目转出 |
| 坏账计提标准显著低于同行 | 财报操纵信号 |

**关键指标：**
```
应收账款周转率 = 营业收入 ÷ 平均应收账款
```
- 周转率下降 = 营收增长有放松销售政策的因素
- 周转率稳定或上升 = 营收增长可靠

**应收票据：**
- 全部是银行承兑汇票 → 企业地位强势（如茅台）
- 商业承兑汇票突然大量增加 → 销售遇困难，开始放松政策
- 票据量与经营规模不匹配 → 可能在票据市场当炒家

**存货（高风险区）：**

> "加大生产可以虚增利润" —— 唐朝

**存货造假的两种手法：**
1. 虚构采购将资金流出体外 → 存货增长远超营业成本增长
2. 加大生产摊薄固定成本 → 存货增加但毛利率上升（最危险信号）

**关键组合判断（唐朝特别强调）：**
```
存货周转率下降 + 毛利率上升 = 强烈造假信号（几乎可以当造假对待）
```
逻辑：存货滞销本应降价促销或增加费用，毛利率应该下降。两者反向变动，违背商业常识。

> **B 型改造**：周期底部备货 → 降级为黄色，需结合产品价格判断。
> **C/D 型改造**：产能爬坡期备货属常态 → 降级为黄色。

**预付账款：**
- 大幅增长，尤其是预付工程款/专利采购款 → 可能通过预付款将资金转出再以收入形式流回
- 超过一年的预付款 → 几乎可以肯定有问题

**其他应收款：**
> "其他应收款就是一个垃圾筐" —— 唐朝
- 优秀公司：其他应收款和其他应付款极小，甚至为零
- 数额较大 → 先当坏人对待（资金被占用或转移）

> **全型适用**：本条与生命周期无关，任何分型下 >总资产 5% 都是红色。

### 2.3 生产相关资产

**在建工程（造假高发区）：**

| 信号 | 含义 |
|------|------|
| 在建工程迟迟不转固定资产 | 虚构项目 或 避免折旧影响利润 |
| 不断追加资金 | 管理层规划失误或过度乐观 |
| 转固后不久又需大修/技改 | 警惕信号 |

**固定资产：**
- 关注折旧年限是否突然变更
- 固定资产异常减值或大修需警惕

**无形资产和商誉：**
- 专利/非专利技术采购金额大 → 可能是通过收购转移资金
- 商誉占净资产比例过高 → 减值风险大
- 频繁收购+大额商誉 → 尝试将商誉还原为资产重新评估

### 2.4 负债和所有者权益

**重点关注：**
- 有息负债的利率 → 利率偏高说明公司有不为认知的问题
- "存贷双高"（大量现金+高息负债）→ 相当于用高音喇叭喊"我是骗子"
- 应付职工薪酬余额波动大 → 可能在用薪酬预提平滑利润

## 第三步：利润表拆解

### 方法论

> "利润表最容易造假。容易造假的根源是权责发生制。" —— 唐朝

**权责发生制要点：没收到的钱可能被算作收入，没付出的钱可能被记录为成本。**

### 3.1 毛利率分析（利润表最重要的指标）

```
毛利率 = (营业收入 - 营业成本) ÷ 营收 × 100%
```

**唐朝毛利率分析框架：**

| 情况 | 分析方向 |
|------|----------|
| 毛利率显著高于同行 | 是否产品竞争力确实强？有无提价支撑？ |
| 毛利率同比大幅波动 | 产品结构变化？单价变动？成本变动？ |
| 毛利率上升 + 存货周转率下降 | **危险信号！可能是加大生产虚增利润** |
| 毛利率上升 + 销量下降 | 警惕——正常情况销量下降不应伴随毛利率上升 |

**毛利率与行业对比是必须项：**
- 同行数据来源：akshare同行业公司、东方财富行业对比
- 偏离同行太多需要解释，无法解释的 → 排除

> **B 型**：对比必须**同期**（周期顶部人人高毛利）。
> **D 型**：弃用——无有效同行可比。

### 3.2 营业利润率（核心利润）

> "营业利润是一家公司的核心利润，是持续竞争力的体现" —— 唐朝

```
营业利润率 = (营收 - 营业成本 - 三费) ÷ 营收 × 100%
```

**必须检验：**
1. 营业利润中，公允价值变动收益 + 投资收益 + 资产减值损失 三者之和的占比
2. 占比突然大幅变化 → 说明"核心利润"被非经营因素严重干扰
3. 营业利润与净利润比例是否基本稳定 → 不稳定说明非经常性因素干扰大

### 3.3 期间费用分析

```
销售费用率 = 销售费用 ÷ 营收
管理费用率 = 管理费用 ÷ 营收
研发费用率 = 研发费用 ÷ 营收
```

**关键规则（唐朝）：**
- 销管费用应和营收同向变动，比例相对稳定
- 销管费用率某年大幅降低且显著低于同行 → 考虑财报操纵
- 销管费用率某年大幅升高 → 管理层可能在新管理层上任时"洗大澡"

> **C/D 型**：研发费用率高是**加分项**而非减分项，不应与销管费用同等对待。

### 3.4 财务费用拆解

```
财务费用 = 利息费用 - 利息收入 + 汇兑损益 + 其他
```

- 海外收入占比高的公司（>30%）：必须评估汇率影响
- 筹资活动现金流中的利息支出 vs 有息负债 → 如果借款利率偏高需要警惕
- 高息借债但资金闲在银行 → 明显报警信号

### 3.5 营业外收支和其他业务收入

- **其他业务收入占比突然大幅提升** → 可能是"主营业务"和"其他业务"之间划转
- **利润主要来自营业外收入** → 令人担忧（偶然收入不可持续）
- **多年发生这种"偶然"** → 可能存在财报操纵

> **D 型**：弃用 #11——早期企业政府补助占比高属正常，需看补助的持续性而非占比。

### 3.6 归母 vs 扣非差异

```
非经常性损益 = 归母净利润 - 扣非净利润
```

- 占比超过10% → 警告信号
- 需查看明细（政府补助、投资收益、资产处置收益等）

## 第四步：现金流量表检验

### 方法论

> "一家企业没有利润也能活，但没有现金今晚8点都熬不过去。" —— 唐朝

### 4.1 经营现金流 vs 净利润（最重要的检验）

```
经营现金流净额 ÷ 净利润 ≥ 1 → 优秀企业的重要特征
```

**判断标准（唐朝）：**

| 经营现金流净额 | 含义 |
|---------------|------|
| < 0 | 入不敷出，需要筹钱度日（银行除外） |
| = 0 | 勉强维持当前规模，无积累 |
| > 0 但 < 折旧摊销 | 只能部分补偿折旧，不具备更新升级能力 |
| = 折旧摊销 | 能维持现状，但无法扩大再生产 |
| > 折旧摊销 | 有潜在成长性，值得投资关注 |

**持续大于1的含义（唐朝）：**
- 公司商品供不应求，买家不断打预付款订货
- 折旧较高的行业（如水电）也可能持续>1
- 注意：房地产行业不适用此指标

**持续小于1的排查：**
- 赊销卖货？→ 验证应收账款
- 存货积压？→ 验证存货变化
- 预付款大增？→ 验证预付款

> **A 型**：用 5 年均值 >0.8（而非每年 >1）。
> **C 型**：允许 <1，但缺口必须被营运资本明细解释（解释度>80%），且缺口增速 < 营收增速。红线：连续 2 期缺口扩大 + 销售收现比 <0.8。
> **D 型**：**弃用**，改用现金续航月数。

### 4.2 销售收到现金 vs 营业收入

```
销售商品提供劳务收到的现金 ÷ 营业收入
```

- 含增值税因素，理想值约1.17（17%增值税率行业）
- 只要大于1 → 销售绝大部分款项已收到，经营良好
- 远小于1 → 大量款项被欠着，产品缺乏竞争力或虚增收入

### 4.3 企业现金流肖像

> "根据现金流三大板块的正负值，建立企业对应肖像" —— 唐朝

| 经营 | 投资 | 筹资 | 肖像 | 关注要点 |
|:----:|:----:|:----|------|----------|
| + | - | + | 成长型企业 | 关注投资回报率和扩张是否在能力圈内 |
| + | - | - | 成熟型企业（自给自足） | 优质类型，用经营现金回报股东+投资扩张 |
| + | + | - | 衰退型企业 | 收缩中，关注收缩原因 |
| - | - | + | 危险型企业 | 靠借债度日+投资扩张，最危险 |
| - | + | + | 投机型企业 | 变卖资产维持+借债，观察投资回报率 |
| + | + | + | 异常型企业 | 经营好但大量分红/还债/出售资产 |
| - | + | - | 混沌型企业 | 无增长但能还债 |
| - | - | - | 濒危型企业 | 全面收缩+入不敷出 |

> ⚠️ **肖像表无生命周期维度，必须叠加分型读数**：
> - 「经营− / 投资+ / 筹资+」在 A 型 = 投机型（卖资产续命）→ 红色
> - 同样的组合在 C/D 型 = 扩产融资期常态 → 需改看投资现金流的**去向**（购建长期资产 vs 理财/股权）

### 4.4 自由现金流（巴菲特概念）

```
自由现金流 ≈ 经营现金流净额 - 购建固定资产无形资产支付的现金
```

- 如果投资主要用于扩大规模而非维持，此计算会低估自由现金流
- 自由现金流是"企业唯一真实的价值"

## 第五步：杜邦分析

### 方法论

> "如果只用一个指标衡量企业优劣，净资产收益率（ROE）是首选。" —— 巴菲特/唐朝

### ROE三因子拆解

```
ROE = 净利润 ÷ 净资产
    = (净利润 ÷ 营收) × (营收 ÷ 总资产) × (总资产 ÷ 净资产)
    = 净利率 × 总资产周转率 × 权益乘数(杠杆)
```

### 三种盈利模式（唐朝命名）

| 模式 | 特征 | 代表 | 优劣 |
|------|------|------|------|
| **茅台模式** | 高净利率 | 茅台、腾讯 | ★★★★★ 一本万利，对管理层要求低 |
| **沃尔玛模式** | 高周转率 | 沃尔玛、京东 | ★★★☆☆ 依赖管理层营运能力 |
| **银行模式** | 高杠杆 | 银行、地产 | ★★☆☆☆ 脆弱，一次意外万劫不复 |

**唐朝的分析要点：**
- 有高净利率产品最好（"只投资傻瓜也能管理的企业"）
- 没有高净利率，就寄托于管理层能力（风险在人的变化）
- 高杠杆是最差的模式，慎重对待

### 杜邦分析步骤

1. 计算ROE及三因子
2. 与同行对比，判断属于哪种模式
3. 拆解ROE变化的原因：是净利率驱动？周转率驱动？还是杠杆驱动？
4. 用现金流量数据验证杜邦分析结果

### ROE筛选标准（**按分型取值，勿一刀切**）

| 分型 | ROE 标准 | 说明 |
|------|---------|------|
| **A 成熟稳定型** | 5 年均值 >15%，近 3 年无一年 <10% | 唐朝原版，但用均值平滑单年扰动 |
| **B 周期重资产型** | 跨周期均值（5–7 年）>8%，且叠加 PB 分位 | 单年不设门槛；若跨周期 ROE<8% 且 PB>70% 分位 → 排除 |
| **C 成长扩张型** | >10% 或不设绝对门槛 | 改看趋势向上 + **周转率不随规模下滑** |
| **D 技术未定型** | **弃用** | 分母失真，改看现金续航 + 里程碑 |

**注意：公司上市当年ROE通常较上市前下跌超过50%**（IPO导致净资产变大而投资项目还没产生收益）

## 第六步：财务排雷

### 12大红色信号（源自唐朝+证监会核查要点）

> ⚠️ **适用分型列是关键**：标注"全型"的与生命周期无关，任何企业都成立；其余需按分型调整。
> 完整调整规则见 `@references/company-archetypes.md`。

#### 资产负债表信号

| # | 信号 | 检验方法 | 适用分型 |
|---|------|----------|---------|
| 1 | **存贷双高** | 货币资金充裕 + 高息有息负债 → 资金可能虚构或被占用 | **全型**（D 型改看现金续航） |
| 2 | **应收账款异常** | 增速远超营收 / 一年以上占比过高 / 回收突然大增 / **应收/净利显著高于同行（横向对比必做）** | A/B 全启用；C 型须看账龄结构；D 型降级 |
| 3 | **存货+毛利率背离** | 存货周转率下降 + 毛利率上升 → 强烈造假信号 | A 型红色；B/C/D 型**降级黄色**（备货常态） |
| 4 | **在建工程异常** | 迟迟不转固 / 不断追加资金 / 转固后即需大修 | **全型** |
| 5 | **其他应收款过大** | 占总资产>5% → 资金被占用或转移 | **全型** |
| 6 | **长期待摊费用大增** | 不恰当使用费用资本化 | **全型** |
| 7 | **商誉过高** | 占净资产>30%且频繁收购 → 减值风险大 | **全型** |

## 第七步：基数异常检验 + 机构预期对比

### 7.1 基数异常检验

**检验方法：**
1. 拉取过去4个同期的数据
2. 标注本期在历史序列中的位置
3. 如果去年同期是离群值 → 必须说明

**常见异常原因：**
- 跨年交付（Q4订单延迟到Q1）
- 政策抢装潮
- 大额一次性收入
- 并表/剥离子公司

**输出：**
```
正常化同比增速 = (本期 / 过去3年同期均值) - 1
```
标注"基数效应导致同比被夸大/缩小了X%"

### 7.2 机构预期对比

| 维度 | 超预期 | 符合预期 | 不及预期 |
|------|--------|----------|----------|
| 净利润 | 实际 > 预期上限 | 在区间内 | 实际 < 预期下限 |
| 毛利率 | 超预期 | 接近预期 | 低于预期 |

**唐朝提醒：** 市场预期（一致预期）是"锚定效应+复制粘贴"的产物，不要盲从。分析时先问"去年同期的基数正常吗"，再判断同比的含金量。

> **D 型**：机构预期往往建立在路演指引上，可信度低。改看**第三方验证**（客户公告、装车/装机、招标中标）而非分析师预测。

### 7.3 全年预期可达性

```
已实现占全年预期比例 = 累计实际值 ÷ 全年一致预期
```

| 报告期 | 合理占比 | 全年超预期线 |
|--------|:--------:|:------------:|
| Q1 | 15-25% | >28% |
| 半年报 | 40-55% | >60% |
| Q3 | 65-80% | >85% |
