# 唐朝核心方法论提炼

> 摘自唐朝《手把手教你读财报：财报是用来排除企业的》
> 整理为AI财报分析的决策框架

## 一、核心理念

### 1.1 财报是用来排除企业的

"财报是用来证伪的，不是用来证实的。反复证伪可以使我们对一个事实的认知更接近真相。"

**对AI分析的指导：**
- 分析目标不是"证明公司好"，而是"排除公司有问题"
- 发现一个无法解释的疑点 → 倾向于排除
- "宁可错杀而少赚，也不能踩雷而亏本"

### 1.2 先看资产负债表

"普通投资者喜欢利润表，投资高手更关注资产负债表。"

**阅读顺序：资产负债表 → 利润表 → 现金流量表**

原因：利润表是权责发生制的产物，容易被操纵。资产负债表上的"痕迹"更难消除。

### 1.3 附注是最重要的帮手

"企业必须披露却又不太想让你明白的东西都在附注里。要想取得比较优势，别人不读的东西，你得读。"

**对AI分析的指导：**
- 任何科目的异常，必须去附注找解释
- 没有合理解释 → 排除
- 附注要逐字细读，尤其是会计政策变更

## 二、资产负债表阅读要点

### 2.1 一个核心公式

```
左边（资产）= 钱的去处
右边（负债+权益）= 钱的来源
```

- 资产按变现难易度排列（货币 → 应收 → 存货 → 固定资产）
- 负债按偿还紧急程度排列（短期借款 → 长期借款）
- 闭上眼想象自己是老板，思考他为何这么干

### 2.2 资产四分类法（唐朝原创）

| 分类 | 包含科目 | 关注重点 |
|------|----------|----------|
| 货币资金 | 现金、银行存款、受限资金 | 是否与债务匹配？是否"存贷双高"？ |
| 经营相关资产 | 应收票据/账款、预付款、存货 | 是否异常增长？坏账计提是否充足？ |
| 生产相关资产 | 固定资产、在建工程、无形资产、商誉 | 在建工程是否迟迟不转固？商誉是否过高？ |
| 投资相关资产 | 长期股权投资、金融资产 | 是否跨行业？投资回报率是否显著>社会平均？ |

### 2.3 四种货币资金危险状态

1. 货币资金 << 短期负债 → 偿债危机
2. 货币充裕 + 高息借款 → 资金虚构/被占用
3. 定期存款多 + 流动资金缺 → 资金受限
4. 其他货币资金巨大 + 无合理解释 → 大股东占用

### 2.4 应收账款的五个信号

1. 增速超营收增速 → 放宽信用/虚增收入
2. 占收入比大且一年以上超三成 → 收入真实性存疑
3. 应收极低（与商业模式不符）→ 收入造假
4. 突然大笔回收 → 现金冲账再转出
5. 坏账计提标准显著低于同行 → 财报操纵

### 2.5 存货的两个造假手法

**手法一：虚构采购流出资金**
- 存货增长远超营业成本增长
- 存货数量/价值不易核查（农林牧渔、软件、生物科技为高危行业）

**手法二：加大生产虚增利润（唐朝独创性发现）**
```
逻辑：固定成本不变 → 产量翻倍 → 单位成本降低 → 毛利率上升
现象：存货增加 + 毛利率上升
判断：存货周转率↓ + 毛利率↑ = 强烈造假信号
```

### 2.6 上下游议价能力

"与同行比照着看，看应收票据、应收账款、应付账款、预付款项、预收款项几个项目，可以看出公司与上下游之间的地位。"

| 指标 | 强势（好） | 弱势（差） |
|------|-----------|-----------|
| 应收账款 | 少或零 | 大量赊销 |
| 预收账款 | 大量（先款后货） | 少或零 |
| 应付账款 | 大量（拖欠供应商） | 少（需现结） |
| 预付账款 | 少 | 大量预付 |

## 三、利润表阅读要点

### 3.1 利润产生过程（两步看）

**第一步：营业收入 → 营业利润（核心）**
- 重点理解权责发生制下收入和费用的确认规则
- 营业利润是持续竞争力的体现

**第二步：营业利润 → 净利润**
- 去掉营业外收支
- 去掉所得税
- 去掉少数股东损益 → 归母净利润

### 3.2 毛利率分析原则

- 毛利率显示产品竞争力
- 必须与同行对比
- 必须看趋势（历史3-5年）
- 异常变动必须找到合理解释

### 3.3 营业利润的构成分析

**营业利润中三个"噪音"科目：**
1. 公允价值变动收益 → 金融资产价格波动，与主业无关
2. 投资收益 → 可能是子公司分红，也可能是金融投资
3. 资产减值损失 → 可能是"洗大澡"

三者之和占营业利润的比例突然大变 → 需要深挖原因

### 3.4 归母净利润 vs 扣非净利润

```
非经常性损益 = 归母 - 扣非
```
- 占比>10% → 警告
- 需查看明细构成

## 四、现金流量表阅读要点

### 4.1 经营现金流净额的五级判断

| 等级 | 条件 | 含义 |
|------|------|------|
| 入不敷出 | < 0 | 靠借债度日 |
| 勉强维持 | = 0 | 无积累，无法更新设备 |
| 补偿折旧 | > 0, < 折旧 | 不具备更新升级能力 |
| 维持现状 | = 折旧 | 无法扩大再生产 |
| 潜在成长 | > 折旧 | 能为扩大再生产提供资金（值得投资关注） |

### 4.2 经营现金流/净利润比率

```
≥ 1 → "印钞机"企业（产品供不应求）
< 1 → 利润质量堪忧
```

例外：房地产行业不适用（卖期房模式导致预收款大）

### 4.3 销售收到现金/营业收入

- 含增值税，理想值约1.17（17%增值税率行业）
- > 1 → 销售绝大部分已回款
- 远 < 1 → 大量款项被欠着

### 4.4 三种企业现金流肖像（最值得关注）

| 类型 | 特征 | 判断 |
|------|------|------|
| + - + (经营+投资-筹资+) | 成长型 | 正常，关注投资回报率 |
| + - - (经营+投资-筹资-) | 成熟型 | 优质，自给自足回报股东 |
| - - + (经营-投资-筹资+) | 危险型 | 最危险，靠借债度日+投资扩张 |

### 4.5 自由现金流

```
自由现金流 ≈ 经营现金流净额 - 购建固定资产无形资产支付的现金
```
- 是"企业唯一真实的价值"
- 持续为正且增长 → 企业在创造价值
- 持续为负 → 企业在毁灭价值

## 五、三大表联动分析

### 5.1 核心联动关系

```
资产 = 负债 + 所有者权益 + 收入 - 费用
```

**推论：虚增利润必虚增资产或虚减负债**
- 虚减负债需要债权人配合，难度大
- 虚增资产只需和自己商量
- 所以上市公司操纵利润90%与资产有关

### 5.2 收入与现金流的验证

```
营业收入 × 1.17 ≈ 销售商品收到现金 + 应收账款/票据增加额
```
- 差异在10%左右属于正常（增值税率、票据等因素）
- 差异过大 → 需要解释

### 5.3 四步财务分析（唐朝总结）

1. **浏览异常** → 三大表快速扫描，发现科目异常
2. **历史分析** → 连续5年以上数据趋势分析（1年异常可信度低）
3. **利润vs现金流趋势** → 两者应保持大致稳定的比例
4. **同行对比** → 避免被孤立的企业增速迷惑

## 六、估值方法（三种）

### 6.1 现金流折现法（巴菲特方法）

- 企业价值 = 未来自由现金流折现值
- 适用于：产品变化小、需求稳定、有持续竞争优势、未来可预测的企业
- 不适用于：初创/科技企业
- 核心是一种"选择企业的原则和大致估算方法"，不是精确计算

### 6.2 清算价值法（格雷厄姆方法）

- 寻找售价低于有形资产账面值的企业
- 关注资产负债表所有有形资产科目

### 6.3 股市价值法（相对估值）

- 选择可比公司，参照PE/PB/PS倍数
- 或预测未来市盈率和净利润，按期望回报率打折确定买入价

**唐朝选择法：** 主要用现金流折现法确定价值区间，参考股市价值法交叉验证。

## 七、造假高危行业

唐朝总结的造假高危行业特征：

| 特征 | 为什么容易造假 |
|------|---------------|
| 税收优惠多 | 造假成本低（不交或少交所得税） |
| 产品不易核查 | 会计师难以验证存货/产量 |
| 产品差异大 | 难找价格参照物 |
| 交货不易监控 | 不好确认是否真的交付了 |

**典型行业：** 农林牧渔、软件、集成电路、生物科技

"对这类公司有兴趣的投资者，必须格外警惕。"
