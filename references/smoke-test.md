## 用例 4 流程（端到端离线）

夹具取 `tests/recheck_probe.py` 的 `LEDGER`/`ANA`/`DRAFT`，写入 `out/600519/2026-06-30/`（底稿.json、分析.json、稿件_成稿.md、稿件.md、数据核对报告.md）：

1. `python3 scripts/recheck.py 600519` 建卷 → 空白卷 `--seal` 应 exit 1（署名/判定未填）
2. 作答（含 Q1 依据不带待解释数字）→ `--seal` 应 exit 1 且指名数字；补出处后 → exit 0（存疑路径须提示披露）
3. 改一题为不通过 → `--seal` 应 exit 1 并给修复指引
4. `python3 scripts/polish.py 600519` scan 建档 → 改写稿 verify 通过 exit 0；塞入新数字 → exit 1
5. 跑完删除夹具目录：`rm -rf out/600519`

注意（见台账 2026-10-31）：基线必须是改写前的**合格**稿——先 scan 合格稿建档，再换入坏稿 verify；拿坏稿当基线会自然通过。
