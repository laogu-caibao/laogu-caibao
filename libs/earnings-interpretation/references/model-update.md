# 财报后预测更新

本文件用于把最新财报实际值和公司指引转化为可解释的预测调整。没有用户原预测、现成模型或足够数据时，不强行生成精确预测。

## 1. 先核验当期实际

| 项目 | 原预测 | 实际值 | 差异 | 原因 | 一次性/持续性 |
|---|---:|---:|---:|---|---|
| 收入 | | | | | |
| 毛利率 | | | | | |
| 营业利润 | | | | | |
| 归母净利润/EPS | | | | | |
| 经营现金流 | | | | | |
| 关键经营指标 | | | | | |

实际值必须与公司披露口径一致。调整后指标与法定指标分开。

## 2. 更新驱动

只调整有新证据支持的假设：

- 量、价、产品结构；
- 原材料、人工、折旧和产能利用率；
- 费用率、税率、汇率；
- 资本开支、营运资本和自由现金流；
- 新指引、订单、产能或管理层可验证表述。

一次性收益或费用不得机械外推。

数据不足时保留原预测或给区间，并说明需要什么信息才能进一步更新。

## 4. 估值边界

只有用户明确要求且数据充分时，才说明更新后预测对估值的影响。估值倍数、WACC、永续增长率等必须写明来源或假设，不把预测值表述为公司指引。

## 5. 输出

1. 当期实际相对原预测的差异；
2. 新指引和经营变量的变化；
3. 原预测 → 新预测/区间；
4. 调整原因和敏感变量；
5. 数据缺口与下一次验证节点。

使用 `update` 模式生成专业 HTML。把“公司指引”“机构预期”“模型推演”作为不同表格列或正文小节展示，不得做成标签墙，也不得互相替代。
