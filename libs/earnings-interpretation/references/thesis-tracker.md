# 财报后的投资逻辑检验

本文件用于判断一份新财报对用户原有投资逻辑的影响，不用于泛化的持仓管理或自动给出买卖指令。

## 1. 把逻辑写成可证伪命题

每条逻辑必须包含：

- 原命题；
- 预期指标和时间窗口；
- 支持证据；
- 可能推翻它的反证；
- 下一次验证节点。

如果没有任何现实数据能推翻一条逻辑，它就不是可检验的投资逻辑。

## 2. 逐条评分

| 逻辑支柱 | 原预期 | 本期证据 | 反证/缺口 | 状态 | 下一步验证 |
|---|---|---|---|---|---|
| | | | | 强化/中性/弱化/证伪 | |

状态含义：

- **强化**：关键指标按预期兑现，且质量或持续性更强；
- **中性**：数据大致符合预期，尚无新增强证据；
- **弱化**：核心指标偏离，但仍可能由周期或一次性因素解释；
- **证伪**：关键假设被明确、持续且难以逆转的证据推翻。

## 3. 证据纪律

- 公司披露、计算和分析推断分开；
- 同时记录支持与不支持原判断的证据；
- 单季度偏差通常不足以单独证伪长期逻辑；
- 管理层目标不等于已实现结果；
- “弱化/证伪”不自动等同于个性化卖出或仓位建议。

## 4. 输出

1. 原投资逻辑；
2. 本期最重要的新信息；
3. 每条逻辑的状态与依据；
4. 反证和数据缺口；
5. 下一期要观察的指标与触发条件；
6. 当前结论的不确定性。

使用 `update` 模式中的“投资逻辑追踪”表展示，不把逻辑状态自动转换为买卖或仓位建议。
