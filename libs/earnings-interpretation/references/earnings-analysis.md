# 已披露财报的标准解读

本文件用于年报、半年报、季报、业绩公告、业绩快报或正式业绩说明会材料已经披露后的标准/深度解读。

## 1. 材料顺序

1. 优先使用用户上传或提供的正式材料；
2. 缺少材料时，定向检索监管披露或公司 IR；
3. 公司业绩公告、正式报告和附注；
4. 公司演示材料与业绩说明会/电话会；
5. 用户问题需要时才补充结构化金融数据；
6. 只有涉及预期差时才获取带日期的一致预期和此前公司指引；
7. 同业或行业材料仅用于解释经营变化。

必须核对所有材料属于同一报告期。用户说“最新”时，先验证披露日期和财政季度，再开始取数。

## 3. 四层拆解

### 结果

一句话说明收入、利润、现金流和指引的总体表现。

### 差异

量化同比、环比、预期差或相对指引的差异。累计与单季必须分开。

### 驱动

拆到分部、地区、产品或经营指标，并归因于量、价、结构、成本、费用、汇率、并购、税率和一次性项目。

### 持续性

将驱动分类为结构性、周期性、一次性或口径性，说明下一期验证指标。

## 4. 必答问题

- 哪个分部贡献最大，哪个分部拖累最大；
- 毛利率和费用率为什么变化；
- 归母与扣非为什么有差异；
- 经营现金流是否支持利润；
- 应收、存货、合同负债和有息负债是否出现风险；
- 新指引相对旧指引发生了什么变化；
- 哪些结论是公司披露，哪些是计算或推断；
- 下一期最值得跟踪的 3–5 个指标是什么。

## 5. 专业报告映射

默认生成专业 HTML，按任务深度选择：

| 模式 | 必备内容 |
|---|---|
| brief | 报告口径、结论、核心指标、主要驱动、现金流/风险提示、来源 |
| standard | brief + 预期差、分部拆解、盈利质量、资产负债表、指引与验证指标 |
| deep | standard + 多期趋势、量价拆解、一次性/周期性/结构性归因和完整证据索引 |

快速版可以缩短篇幅，但不能静默删除口径、现金流、资产负债表风险和来源。详细版式读取 `professional-report.md`。

## 6. 交付检查

- 报告期、币种、单位、会计准则和累计/单季无误；
- 核心数字可追溯到具体文档和页码/章节；
- 预期数据带来源和形成日期；
- 同比、环比、差异比例和基点计算正确；
- 事实、计算和推断已区分；
- 没有把一次性改善写成结构性趋势；
- 结论与正文证据一致；
- 不主动扩展为行业选股、技术面监控或个性化仓位建议。
- 材料足够时没有额外调用 Web Search 或金融 MCP；
- 最终 HTML 自包含、无远程脚本并通过自动校验。
