# 财报解读核心分析框架

本文件是所有财报解读案例的必读参考，只覆盖数据口径、三大报表、勾稽关系、盈利质量与财务红旗。

## 1. 先统一口径

提取数字前确认：

- 公司全称、证券代码、市场；
- 报告类型、报告期、披露日期和财政年度；
- 合并或母公司口径；
- 币种与单位；
- 中国会计准则、IFRS 或 US GAAP；
- 累计或单季、法定或调整后、归母或全部业务。

累计数与单季数不得直接比较。用累计数相减还原单季时，明确标注“计算值”。重述、并购并表、汇率、股本和会计政策变化必须单独说明。

## 2. 三大报表最小提取集

### 利润表

| 项目 | 必看问题 |
|---|---|
| 营业收入 | 同比/环比、分部与量价驱动 |
| 毛利率 | 产品结构、价格、成本和产能利用率 |
| 销售/管理/研发费用率 | 投入是否有效，是否靠收缩式降费增利 |
| 营业利润 | 主业盈利能力 |
| 归母与扣非净利润 | 一次性损益对利润的影响 |
| EPS | 股本、回购、增发和可转债稀释 |

### 资产负债表

| 项目 | 必看问题 |
|---|---|
| 货币资金与短期有息负债 | 流动性安全垫 |
| 应收账款/票据 | 增速是否持续高于收入，账龄与减值 |
| 存货 | 增速、周转、跌价和产品结构 |
| 合同负债 | 预收变化及未来收入信号 |
| 固定资产/在建工程 | 扩产节奏和产能消化 |
| 商誉 | 被并购标的表现与减值风险 |
| 有息负债 | 规模、期限、利率和偿债压力 |
| 股东权益 | ROE 分母及少数股东影响 |

### 现金流量表

| 项目 | 必看问题 |
|---|---|
| 经营现金流 CFO | 利润是否真正变成现金 |
| 资本开支 Capex | 维持性或扩张性投入 |
| 自由现金流 FCF | `CFO - Capex`，注明为近似值 |
| 投资/筹资现金流 | 收购、融资、还债、回购和分红 |
| 期末现金 | 与资产负债表勾稽，关注受限资金 |

## 3. 常用计算

- 毛利率 = 毛利 / 营业收入
- 净利率 = 归母净利润 / 营业收入
- 营收同比 = `(本期 - 上年同期) / 上年同期`
- 单季环比 = `(本季 - 上季) / 上季`，需考虑季节性
- 资产负债率 = 总负债 / 总资产
- 现金短债比 = 货币资金 / 短期有息负债
- 净现比 = 经营现金流 / 归母净利润
- 应收周转天数 = 平均应收 / 营业收入 × 期间天数
- 存货周转天数 = 平均存货 / 营业成本 × 期间天数
- ROE = 净利率 × 总资产周转率 × 权益乘数

百分比变化写 `pct`，利润率变化写 `bps`。分母为零、负数或口径不一致时，不强行计算。

## 4. 必做勾稽

1. 归母净利润、扣非净利润、经营现金流是否同向；
2. 应收增速是否持续高于收入增速；
3. 存货增速是否持续高于收入或成本增速；
4. 分部合计是否与公司总额一致；
5. 现金流量表期末现金是否与资产负债表匹配；
6. EPS 是否能由净利润和加权股数合理解释；
7. 财务费用是否与有息负债、利率和汇兑变化匹配；
8. 当前指引是否与上一期指引使用同一口径。

勾稽失败不等于造假。先排查口径、重述、受限资金、并表和季节性，再描述风险。

## 5. 盈利质量与红旗

重点检查：

- 增收不增现、净现比长期偏低；
- 应收或存货持续显著快于收入；
- 归母利润主要由补助、处置、公允价值、投资收益或减值转回贡献；
- 毛利率异常波动且缺乏经营解释；
- 货币资金充裕但高额借款并存；
- 现金短债比低、短债集中到期；
- 商誉高且被并购标的持续不达预期；
- 研发资本化、费用递延或调整后利润口径异常；
- 会计政策频繁变化、非标审计意见、重大关联交易。

不要根据单季度营运资本波动直接下结论；至少结合商业模式、季节性和多个期间验证。

## 6. 驱动归因

把变化拆成：

- 量：销量、出货、用户或门店；
- 价：ASP、折扣、产品结构；
- 成本：原材料、人工、折旧、产能利用率；
- 费用：销售、管理、研发、股权激励；
- 税率与财务项目；
- 汇率和并购；
- 一次性、周期性、结构性和口径性影响。

结论使用“现象 + 数据 + 原因 + 持续性/影响”。无法验证原因时写“可能与……有关，仍需……验证”。

## 7. 报告类型差异

| 类型 | 重点 |
|---|---|
| 年报 | 附注、审计意见、完整三表、长期趋势 |
| 半年报 | 上半年趋势、全年目标与季节性 |
| 季报 | 单季拐点，注意披露颗粒度较低 |
| 业绩预告 | 利润区间与变动原因，以正式报告为准 |
| 业绩快报 | 核心数字快速判断，以正式报告和审计结果为准 |

## 8. 材料与工具路由

先判断材料是否足够，再决定工具：

| 当前材料 | 默认动作 | 何时扩展 |
|---|---|---|
| 用户上传完整财报 | 直接读取并分析 | 缺页、口径冲突或用户要求外部数据 |
| 用户提供正式财报链接 | 直接读取并分析 | 同上 |
| 只有公司与报告期/月度 | 定向检索监管披露或公司 IR | 找到并核验正式报告后停止 |
| 真实 A/HK/US 上市公司 | 正式原文门禁后调用一次金融 MCP | 合并查询当前价与当前总市值，绑定 `MARKET_SNAPSHOT` |
| 需要多期字段、预期、其他行情、估值或资讯 | 在财报原文基础上调用金融 MCP | 只查询明确缺失字段 |

工具越多不代表越专业。优先选择能回答用户问题的最短充分路径。
